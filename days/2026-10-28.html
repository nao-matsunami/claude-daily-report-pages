A. Claude Code(最重視)

Claude の「2.1.305〜2.1.312 の8リリース、10/20〜10/27」は changelog の日付と一致します。

A-1. v2.1.311(10/26):CLAUDE.md とコンテキスト管理の修正

  • [確認済]
  • 長いリスト項目を含む CLAUDE.md で固まる問題を修正しました。自動圧縮の直後に古い CLAUDE.md / MEMORY.md が見える問題も修正されています。
  • 標準コンテキストで 200K を超えた場合、「Usage credits required for 1M context」で止まらず、圧縮して続行するようになりました。前の2点は両AIが一致、最後の点は codex のみが挙げていた内容で、いずれも原文で確認しました。
  • 出典:changelog

A-2. v2.1.311:サブエージェントと hooks の余計な実行を修正

  • [確認済]
  • SubagentStop が、実行中のサブエージェントごとに「1分に約2回」発火していた問題を修正しました。
  • クラウドやバックグラウンドのセッションを再開したとき、完了済みの /code-review などが再実行される問題も修正されています。
  • サブエージェント起動後に接続した MCP のツールが使えない問題も修正されました。これは両AIが一致しています。
  • 出典:同上

A-3. v2.1.311:ultrathink が xhigh で動くように

  • [確認済]
  • Claude のみが挙げた項目です。原文では「対話ターミナルでの」ultrathink に限られ、Anthropic API 経由の Opus 5.5 / Sonnet 5.5 / Haiku 5.5 / Fable 5.1 が対象です。claude -p まで対象になるとは書かれていません。

A-4. v2.1.311:DISABLE_COMPACT はオフにする方向だけに

  • [確認済]
  • settings と mod の $.env.set では、圧縮をオフにすることしかできなくなりました。オンに戻す用途には使えません。Claude のみが挙げた項目です。

A-5. v2.1.311:「Running UserPromptSubmit hooks」表示

  • [確認済]
  • 原文では [VSCode] 限定です。Claude の出力にはこの限定が書かれていなかったので、ここで補います。

A-6. v2.1.310(10/23):圧縮の失敗ループと -p のメモリ使用量を改善

  • [確認済]
  • base64 や SVG のような密度の高い会話で、「Prompt is too long」の後の圧縮が足りず、再び失敗する問題を修正しました。
  • 非対話(-p / Agent SDK)で、巨大な transcript を圧縮するときのメモリ使用量も改善されています。codex のみが挙げた項目です。

A-7. v2.1.310:Monitor の対応環境を拡大

  • [確認済]
  • Bedrock / Vertex / Foundry、およびテレメトリなどを無効にした環境で、Monitor ツールとプラグインモニターが使えるようになりました。同じ環境で長時間の前景 sleep もブロックされます。両AIが一致しています。

A-8. v2.1.310:Enterprise カスタムロールと、MCP タイムアウト時のエラー文

  • [確認済]
  • クラウドセッションと Remote Control の権限を、Enterprise のカスタムロールで割り当てられるようになりました。
  • MCP のエラー文の変更は、Claude の要約より条件が狭いです。原文の条件は「非対話セッションで、サーバーの elicitation が未回答のままタイムアウトした場合」で、そのときに「繰り返すな」と伝えるエラーになります。

A-9. v2.1.309(10/22):sed -i と /rewind、claude ultrareview のワークスペース信頼

  • [確認済]
  • Claude は --trust-workspace を「二次情報のみ」としていましたが、今回 changelog の原文で確認できました。

A-10. v2.1.309:巨大なネスト CLAUDE.md と skills の探索

  • [確認済]
  • サイズ上限を超えたネスト CLAUDE.md は、先頭部分だけが読み込まれるようになりました。
  • --add-dir 先にある同名の skill は <folder>:<name> で呼び出せます。
  • シェルで変更したネストパッケージの skill を /verify や /code-review が見つけられない問題も修正されました。この項目は codex のみが挙げたものです。
  • 「重要な指示を末尾に置かない」という助言は、codex 自身が明記しているとおり、変更内容から導いた推論です。

A-11. v2.1.309〜310:Windows の hooks が fail-open になる問題

  • [確認済]
  • PowerShell の hook が終了コード2でブロックしない問題を修正しました。
  • Git for Windows や Git Bash がない環境で、PreToolUse / PermissionRequest の hook が素通りになる問題も修正されています。codex のみが挙げた項目です。

A-12. v2.1.312(10/27):システムプロンプト、テレメトリ、表記の変更

  • [確認済]
  • Bedrock / Vertex / Foundry / Mantle で、認識されないモデル名には短いシステムプロンプトが使われます。従来のプロンプトに戻すには CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT=0 を設定します。
  • claude_code.safety_event は送信されなくなりました。このイベントは 2.1.307 で追加されたばかりです。
  • 「session limit」の表記が「5-hour limit」に変わりました。
  • oidc.user_id_claim が追加され、クラウドルーティンでモデルピッカーから effort を指定できるようになりました。以上は Claude のみが挙げた項目です。

A-13. v2.1.307(10/21):/claude-api api-version、@claude review stop、checkout hook

  • [確認済]
  • self-hosted runner の checkout hook は、既定で30分で停止し、セッションのセットアップが失敗するようになりました。延ばすには --checkout-hook-timeout-min を指定します。
  • 既存の self-hosted-runner の知見に、この既定タイムアウトの記載があるかは見直したほうがよいです。

A-14. v2.1.305 / 306:サンドボックスとエラー表示

  • [確認済]

  • MCP ツールが多いセッションで、本来の API エラーが「prompt is too long」に置き換わる問題を修正しました(2.1.306)。
  • 同じ 2.1.305 には allowedMcpServers の変更も入っています。両AIとも触れていませんが、検証済みです。

今日の注目

  1. v2.1.311 のサブエージェントと hooks の修正(A-2)
  • SubagentStop が1分に約2回発火していた問題が修正されたので、SubagentStop に重い処理や外部への通知をつないでいる箇所がないか洗い出す価値があります。修正前のログに、重複コミットや二重通知が混ざっていた可能性もあります。
  • 標準コンテキストで 200K を超えたときに止まらず圧縮して続行するようになった点も、無人運用の止まり方を変えます。
  1. CLAUDE.md のサイズと形の扱い(A-1、A-10)
  • サイズ上限を超えたネスト CLAUDE.md は先頭部分だけが読み込まれます(2.1.309)。長いリスト項目は固まる原因でした(2.1.311)。
  1. v2.1.312 の CLAUDE_CODE_SIMPLE_SYSTEM_PROMPT と、safety_event の送信停止(A-12)
  • Bedrock / Vertex / gateway を経由し、カスタムのデプロイ名や推論プロファイル ARN を使っている環境では、黙ってシステムプロンプトが短くなります。
  • OTel で claude_code.safety_event を集計している場合は、10/27 以降にデータが途切れます。どちらも気づきにくい変化なので、該当するかだけでも確かめる価値があります。
