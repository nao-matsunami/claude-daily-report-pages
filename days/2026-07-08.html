クラウドでのバックグラウンド実行（端末オフラインでも継続）

  • ⚠️ ただし Gemini の言う機能名 「Dispatch」は裏が取れず[要検証]。公式・報道とも固有名は確認できず、"remote execution beta"／"cloud background" と表現されている。Geminiの命名は捏造の疑い。

チャットとCoworkのホーム統合

  • [確認済] codex/Claude一致 + 公式。1つのホームにプロジェクト/アーティファクトを集約。

利用上限の一時倍増キャンペーン

2. Claude Code（最重視領域）

デフォルト権限モードが「Manual」に変更（v2.1.200 / 7月3日）

  • [確認済] 3AI一致 + 公式チェンジログ/公式Xで確認。CLI/VS Code/JetBrains全体でManual化。AskUserQuestionダイアログが既定で自動継続しないよう変更（/configでアイドルタイムアウト設定可）。
  • 出典: code.claude.com/docs/en/changelog / @ClaudeCodeLog

v2.1.202（7月6日）

  • [確認済（内容は一部相違）] リリース自体は確認。Claudeは「Dynamic workflow size 設定追加//reviewを単一パスに戻す」等と記載。一方ある要約は「内部改善のみ、ユーザー向け変更なし」と記述。細部は要一次確認だが、7/6リリース自体は[確認済]。

「ステルスマーカー（隠しトラッカー）」問題とコード削除

  • [確認済] Geminiのみ詳述だが、複数報道 + Anthropic技術者のX上の認めで裏取り完了。中国リージョン（Asia/Shanghai等）判定でシステムプロンプト日付文字列にプロンプト・ステガノグラフィで隠しマーカーを埋め込んでいたのを研究者"Thereallo"が発見。Anthropicは「3月開始の実験、リセラー不正・蒸留対策」と説明し削除。
  • ⚠️ 補足：Geminiの「7/1に削除」は日付未確認。Alibabaのban発効は7/10（Geminiの「7/7までに禁止」は不正確）。
  • 出典: Malwarebytes / The Next Web

今日の注目（検証・実装を試す価値がある更新）

  1. Claude Code v2.1.200：デフォルト権限モードの「Manual」化 [確認済]

→ 既存の自動化スクリプト・CI連携・IDE統合の挙動が変わる破壊的変更。承認フローの前提が崩れる恐れがあるため、最優先で自環境の動作確認を推奨。/configのアイドルタイムアウト設定も併せて検証価値が高い。

  1. Claude Cowork のウェブ／モバイル + クラウド継続実行 [確認済]

→ 端末オフラインでもタスク継続という非同期エージェント運用の実用性を、実際のワークフロー（レポート集約等）で試す価値あり。ただし機能名「Dispatch」は使わないこと（未確認）。

  1. Fable 5 再展開の一時50%枠 [確認済・ただし期限に注意]

→ 週次上限の最大50%までFable 5を使える枠は公式では7月7日まで（Geminiの「7/12〜13」は誤り）。本日7/8時点では既に終了しクレジット制へ移行している可能性が高いので、実際の課金挙動を確認してから使うべき。
