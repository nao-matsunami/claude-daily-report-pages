今日の注目

  1. 2.1.281 での auto mode の変更（CLAUDE_CODE_AUTO_MODE_SERVER の直接API適用 + サーバー側での read-only shell 審査）
  2. Opus 5.5 の既定化に伴う effort とモデルの再固定（2.1.280）
  • 次の3つが同時に起きています。
  • 既定 Opus が Opus 5.5 に変わった。
  • per-model 化より前に保存した effort が新モデルには効かず、既定の medium から始まる。
  • Pro/Team Standard の既定モデルが Opus になった。
  • その結果、定期実行ジョブの品質とコストが気付かないうちに変わる可能性があります。ANTHROPIC_MODEL と effort を明示しているかを点検する価値があります。
  1. CLAUDE_CODE_SUBAGENT_PROMPT_CACHE_TTL=1h の効果測定

長いサブエージェント処理で cache write が減るという主張は、個人の計測しかありません。1h の cache write は $8 と高いため、/usage などで before/after を実測してから採用するかを決めるべきです。
