Claude Code（最重視）

CLIリリース 2.1.206〜2.1.211 — [確認済]
公式changelogで日付まで確認。2.1.211（7/15）は --forward-subagent-text フラグと双方向オーバーライド文字（bidi）の権限プレビュー無害化を追加。2.1.210（7/14）は isolation: 'worktree' のサブエージェントがメインリポジトリをgit操作できてしまう不具合を修正。2.1.208（7/14）はスクリーンリーダーモード、vimInsertModeRemaps、CLAUDE_CODE_PROCESS_WRAPPER。2.1.207（7/11）はBedrock/Vertex/Foundryでauto modeがオプトイン不要になり、既定モデルがOpus 4.8へ。
→ codexが「2.1.210/2.1.211は日付未確認」としていた点は解消しました（7/14と7/15）。Claudeの「2.1.206は7/10」は誤りで、正しくは7/9です。

今日の注目

1. 会話途中のシステムメッセージ（7/15） — 一番新しく、一番試す価値があります。ベータヘッダー不要でOpus 4.8を含む主要モデルとBedrock/Vertexで既に動くため、今日そのままAPIで叩けます。長時間走るエージェントの途中で方針を差し込む用途に直結し、しかも3AIのうちcodexしか拾えていない = 見落とされやすい更新です。

2. Claude Code 2.1.211 の --forward-subagent-text（7/15） — サブエージェントのテキストと思考をstream-json出力に流せます。サブエージェントをオーケストレーションしていると中間状態が見えないのが定番の不満なので、それが直接解消します。フラグ1つで検証できるのも良い点です。

3. isolation: 'worktree' の修正（2.1.210、7/14） — これは新機能ではなくバグ修正ですが、影響が大きいので挙げます。worktree隔離したはずのサブエージェントがメインリポジトリに対してgit変更コマンドを実行できてしまっていました。並列エージェントでworktree隔離に依存している場合、隔離が効いていると思っていた期間の作業を疑う理由になります。アップデートを優先してください。

（/design-sync と /design のどちらが正しいコマンド名かは未解決です。実機で確認するのが確実です。）
