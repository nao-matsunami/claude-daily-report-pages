今日の注目（検証・実装を試す価値のある更新）

  1. Artifacts in Claude Code（6/18） — Team/Enterpriseベータ。セッションのコンテキスト（コードベース＋コネクタ＋会話）からライブ更新Webページを生成しチーム共有。PR walkthrough・インシデントページ等、実運用ワークフローに直結するため最も試す価値が高い。
  1. Claude Code 2.1.183 の Auto mode 安全強化（6/19） — terraform/pulumi/cdk destroyや破壊的gitコマンドの自動ブロック。Auto modeを常用する環境では挙動が変わるため、バージョンアップ前に確認推奨。
  1. Claude Design × Claude Code 双方向連携（6/17） — /design-syncでデザインシステムを取り込み、スクリーンショットではなく既存作業からClaude Codeへハンドオフ。デザイン→実装の往復を扱うチームは試す価値あり。ただし利用量カウント仕様が公式ドキュメント間で矛盾しているため、コスト面は事前検証が必要。
