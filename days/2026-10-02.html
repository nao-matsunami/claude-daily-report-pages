[確認済] モデルIDは claude-sonnet-5-5。料金は100万トークンあたり入力 $2、出力 $10、キャッシュ読み取り $0.20、キャッシュ書き込み $2.50。ベンチマーク（Terminal-Bench 4.0 が 70.6%、CursorBench 4.0 が 55.5%、GDPval-AA が 1844）、リスクの高い依頼を Sonnet 5 に回すサイバー安全策、推論抽出を防ぐ分類器も、製品ページの記述と一致しました。（確認経路: 製品ページと Release Notes を直接取得）

Sonnet 5.5 の破壊的変更

収集が載せていなかった変更も1つありました。advisor tool が Opus 4.8 / 4.7 / Sonnet 5 を advisor として受け付けなくなっています。

2. Claude Code

2.1.287（10-01）Claude Mods

[確認済] changelog、管理者向けドキュメント、claude.com の公式ブログ（10-01）で確認しました。

  • mod はデフォルトでオン（v2.1.287 以降）。サンドボックス化はされません。
  • 組み込み mod「You should know」は /plugin enable cc-plugin-you-should-know@builtin で有効にします。changelog には「first-party でテレメトリがオンのセッション」という条件が付いています。
  • 管理者向けドキュメントには、運用上大事な点が書かれています。
  • auto mode では、mod が承認した呼び出しは分類器のチェックを通らずに実行される
  • ask ルールや、managed 以外の PreToolUse hook は mod が上書きできる
  • CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=0 は v2.1.287 以降無視される
  • 止めたい場合は managed settings で allowManagedModsOnly を使う

claude.dev については、公式ブログが「our guide」として claude.dev の記事にリンクしていました。Anthropic が運営している可能性は高いですが、ドメインの所有者は直接確認していません。
出典:

  • https://code.claude.com/docs/en/plugins/mods/admin
  • https://claude.com/blog/claude-code-mods
