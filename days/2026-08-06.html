6. 今日の注目（検証・実装を試す価値がある更新）

① prompt-audit サブコマンド（v2.1.221）— 最も試す価値が高い

② v2.1.222 の PreToolUse auto-allow フックのバイパス修正 — 実機確認の価値

バックグラウンドエージェントのタスク（要約・compaction・リネーム）で auto-allow フックがツール制限を回避できていた。理由：あなたは hooks 運用の知見を既に蓄積しており、この修正は既存の hooks 設定の実効範囲を変える可能性がある。加えて worktree 分離セッションの破壊的 git コマンド問題も同版で修正されているため、更新優先度は高い。修正前後の挙動差は claude -p の非対話実行で検証しやすい。

③ background セッションの挙動変更 + /fork の worktree 独立化（v2.1.221）

background セッションが commit & push し、CLAUDE.md の git 指示に従い、必要時のみ draft PR を開くよう変更された。理由：CLAUDE.md に git / PR 方針を書く実効性が上がったという明確な仕様変更であり、「書けば効く」ことを実機で確認できれば CLAUDE.md 設計の指針に直結する。/fork の worktree 独立化とあわせて、並列作業時の衝突挙動を一度実測しておく価値がある。
