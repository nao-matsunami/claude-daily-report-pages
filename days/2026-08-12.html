3AI(agy/codex/claude)突き合わせ + Claude審判。確度ラベルを必ず確認すること。

3AIの出力を突き合わせ、主要項目は一次情報（code.claude.com / platform.claude.com / support.claude.com / claude.com/blog / anthropic.com）で確認しました。以下、確度ラベル付きの統合結果です。

1. Claude Code（最重視）

クロスセッション・メッセージング（v2.1.224 / 8月7日）

[確認済] 同一ユーザーの Claude Code セッション同士が ListAgents で相手を発見し SendMessage でテキストのみを送れる。会話履歴・ファイルは渡らず、macOS / Linux 限定。v2.1.225 で Remote Control 経由の他マシンセッションにも送信開始が可能に（name [ref] 表示）、v2.1.228 で受信表示がインライン化。
※ Gemini の「v2.1.227」は版数誤り（正: v2.1.224、Week 32 digest と CHANGELOG で確認）。
https://code.claude.com/docs/en/whats-new/2026-w32 / https://code.claude.com/docs/en/cross-session-messaging

セルフホスト環境 public beta（v2.1.224 / Team・Enterprise）

[確認済] claude self-hosted-runner setup で自社マシン/コンテナをランナー化し、claude.ai・モバイル・デスクトップ・claude --cloud から起動したクラウドセッションを自社ネットワーク内で実行。Owner/admin が管理画面で「Allow self-hosted environments」を有効化する必要あり。3AI一致。
https://code.claude.com/docs/en/self-hosted-environments-quickstart

auto mode がデフォルトに（8月14日 / Pro・Max・Team の新規セッション）

[確認済] 自分でデフォルトを設定済みなら維持、組織管理のデフォルトも不変。分類器呼び出しは使用量上限にカウントされない（適用済み）。公式ブログの数値は原文で一致確認: 有償テスター 1,053人、危険コマンド検知 人間レビュー13.6% vs auto mode 89%、意図しない有害操作 6.3% vs 2.4%、プロンプトインジェクション 720件中0件成功。無効化は disableAutoMode。
※ Gemini の「手動承認では承認疲れで拒否率が13.6%にとどまる」は数字の読み違え。13.6% は「人間レビューが危険コマンドを検知できた率」であり拒否率ではない → その解釈部分は [棄却]。
https://claude.com/blog/auto-mode-default-in-claude-code

Week 32 のその他の変更（すべて公式 digest で確認）

[確認済] ・200サブエージェント/セッションの上限撤廃（同時実行数・深さ上限は継続）・/fork が独自 worktree を作成・worktree 隔離が Bash コマンドと git リダイレクトにも拡大・PreToolUse auto-allow フックが内部サイドタスク（要約・コンパクション）でツール制限を迂回する問題の修正・/review が /code-review のエイリアス化＋レベル省略時は前回値再利用・/ultraplan research preview 削除・プラグインの archive（HTTPS zip + SHA-256 ピン）ソース追加・バックグラウンドセッションが commit & push し CLAUDE.md の git 指示に従う・リポジトリのチェックイン設定から Remote Control 自動接続を有効化不可に・サンドボックス認証情報マスキング（mode: "mask" 等、Linux/WSL2）・VS Code の Focus view。
→ この一群は Claude の出力のみが網羅、Gemini は未言及、codex は一部のみ。Claude 側が正確。
https://code.claude.com/docs/en/whats-new/2026-w32

v2.1.225 / 2.1.226 / 2.1.227 / 2.1.228

[確認済] 2.1.225（8/8）: gateway spend-limit 表示、claude agents の workspace trust プロンプト、ヘッドレスの OAuth 401、MCP OAuth の keychain タイムアウト、巨大会話 compaction 後の Remote Control resume、self-hosted-runner --base-dir の起動時エラー化 ほか。2.1.226（8/8）はバグ修正のみ。2.1.227（8/10）: Max ユーザーへの Fable クレジット誤プロンプト、claude-code-action の Bash 全失敗、/tui、スラッシュコマンドメニュー、イベントループ停滞の低減。2.1.228: レイアウト内部エラー後の再描画停止、Windows の git 探索、Remote Control /resume の会話データ漏れ、Write ツール権限を Edit と揃える ほか。
[要検証] 2.1.228 のリリース日は取得したページ上で明示を確認できず（Claude も同旨）。Claude が挙げた「セッションクリーンアップがプロジェクトのメモリフォルダを消す不具合」「synced skills がローカルコマンドをシャドウイングしない強化」は今回取得した要約に現れず、未確認（存在しないという確認ではない）。
https://code.claude.com/docs/en/changelog / https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md

CLAUDE_CODE_DISABLE_1M_CONTEXT の挙動変更（v2.1.223）

[確認済] ネイティブ1Mウィンドウを持つ全モデルに適用、未知モデルIDも auto-compact 対象（復帰は CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1）。Claude のみが報告。

5. 二次情報（コミュニティ実践知）

いずれも公式の裏付けなし。数値・固有名は各記事の主張です。

  • [要検証] CLAUDE.md は 60〜200行（最大300行）、150〜200ルール超で追従性低下 — 具体的な閾値の出所は不明。
  • [要検証] 「Mr. Tinkleberry テスト」（隠しルールの脱落でコンテキスト溢れを検知）— Gemini 単独。実在するコミュニティ小技かどうか裏取りできず。
  • [要検証] 同時サブエージェントは3〜5体が最適 — 個人の経験則。なお200体上限は今週撤廃されており、上限とは別の話。
  • [要検証] Skill の context: fork / CLAUDE_CODE_FORK_SUBAGENT=1 — Claude 自身が「バージョン・環境変数名とも未確認」と明記。
  • [要検証] /compact は70〜80%で手動、自動は76〜83%で発火 — 観測値、公式仕様の確認なし。
