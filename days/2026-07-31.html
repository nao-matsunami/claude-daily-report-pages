[確認済] 2026-07-24 公開。モデルID claude-opus-5、$5/$25 per MTok（Opus 4.8と同額）、claude.ai / API / Claude Code / Claude Cowork を含む全プラットフォームで同日提供。安全分類でフラグされたリクエストは既定でOpus 4.8へフォールバックする旨も公式発表に明記。fast modeは基本価格の2倍・約2.5倍速。3AI一致＋公式ページで確認。

  • https://platform.claude.com/docs/en/release-notes/overview

破壊的変更: thinking無効化がeffort high以下に制限

[確認済] Opus 5では thinking: {"type":"disabled"} を xhigh/max と併用すると400エラー。加えてthinkingが既定ONになったため、thinking未指定のコードは挙動・トークン消費が変わります。codexとClaudeが一致、公式リファレンスでも確認。Geminiはこの項目に言及なし。

effort 5段階 / Opus 4.7 fast mode 廃止 / mid-conversation tool changes (beta) / fallbacks: "default" (beta)

[確認済] いずれもcodex・Claude一致＋公式リファレンスで確認。ベータヘッダは mid-conversation-tool-changes-2026-07-01、server-side-fallback-2026-07-01。

MCP 2026-07-28 仕様への対応

[確認済] 2026-07-28公開。(1) コアのステートレス化（サーバレス/エッジ配備可）、(2) MCP Apps / Tasks のバージョン管理された拡張としての標準化、(3) 本番OAuth 2.0 / OIDC準拠の認可強化（Entra・Okta等）。数値も一次情報で確認: SDK月間DL 4億超（年間4倍）、コネクタディレクトリ950サーバ超。Claude側ではMCP Apps・IdP経由のエンタープライズ認証・オブザーバビリティダッシュボード・MCPトンネル（リサーチプレビュー）を順次展開。

今日の注目 — 検証・実装を試す価値がある更新

  1. サブエージェントのネスト深度が既定1→3に（Claude Code 2.1.219）

既存のエージェント構成の挙動が黙って変わる種類の変更です。多段委譲が自動で発生するようになったため、コスト・レイテンシが予期せず増える可能性があります。まず CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1 との比較で、自分のワークフローが恩恵を受けるのか単に膨らむだけなのかを測るのが最も費用対効果が高い検証です。Dynamic workflows の既定 medium 化（15エージェント未満）も同時に効いてきます。

  1. Opus 5 の thinking 既定ON + effort xhigh/max での disabled 禁止

これは API を叩いているコードが実際に壊れる／課金が変わる唯一の項目です。thinking 未指定のルートは今後thinkingトークンを消費し、max_tokens がthinking+本文の合計上限であるため応答が途中で切れ得ます。既存の thinking: disabled × xhigh の組み合わせは400になります。今日中に該当箇所を洗い出す価値があります。

  1. MCP 2026-07-28 のステートレスコアとOAuth/OIDC強化

自作MCPサーバを持っているなら、サーバレス/エッジへ載せ替えられるようになった点が構成の選択肢を変えます。加えてMCP Apps（会話内インタラクティブUI）とMCPトンネル（プライベートネットワーク、リサーチプレビュー）は、社内リソース接続の設計を見直す実利があります。ただし段階展開中なので、まず自環境で何が到達しているかの確認から。
