8. 研究・コミュニティ

arXiv 3本（codex 単独主張 → 全て実在を確認）

[確認済]

  • 2608.11095「Why Does CLAUDE.md Keep Growing? Catastrophic Remembering in Agentic Coding」 — 1,867リポジトリ・247,694件の指示ライフタイムを分析。エージェント用プロンプトは生涯で +226%（3倍超）、1コミットあたり +4.9 命令増加し、古い指示ほど削除されにくい。理由が失われた指示の安全な削除コストが O(2^|D|) になることが原因。 https://arxiv.org/abs/2608.11095
  • 2608.10906「GitSkills: A Dataset of Agent Skills on GitHub」 — 282,200リポジトリから 3,797,117件の SKILL.md（2026年7月収集）。中央レジストリもパッケージマネージャも無く、フォルダのコピーで伝播。MSR '27 採録。 https://arxiv.org/abs/2608.10906
  • 2608.08453「What Keeps Agent Skills from Being Reusable? Evidence from 138K SKILL.md Files」（8/9投稿） — 20,556リポジトリの 138,133件を分析し、91.8% が1つ以上の欠陥を含む。spec-aware なスキルは良好、AI生成スキルは安全性・可搬性の問題が多い。 https://arxiv.org/abs/2608.08453

今日の注目

1. claude-api スキルの 200k → 25k 削減（v2.1.234）を自作スキルに適用する

公式が「参照ドキュメントをオンデマンド読み込みにする」という設計変更で 1スキルあたり175k トークンを削っています。これは記事の主張ではなく changelog の一次事実です。fresh session で /context を1回叩き、自分のスキルとMCPツール定義が何トークン占めているかを実測すれば、同じパターン（SKILL.md 本体は薄く、詳細は references/ へ）が自分の環境でいくら効くか即日で数値化できます。上記の 8/14 公式Tips が /context を明示的に推奨しているのも同じ文脈です。

2. Todo/Task ツールの廃止（v2.1.233）が CLAUDE.md に残った指示と衝突していないか点検する

Opus 4.8 / Sonnet 5 / Fable 5 / Mythos 5 以降で TodoWrite / TaskCreate 系が利用不可になりました。CLAUDE.md や skills に「TODOリストを都度更新せよ」系の指示が残っていると、存在しないツールを指す死んだ指示になります。arXiv 2608.11095 の「古い指示ほど削除されない（+226%成長）」という定量結果とも噛み合う、削除判断が明確につく具体例です。CLAUDE_CODE_ENABLE_TODO_TOOLS=1 で戻せるので、戻すか指示を消すかの二択で決着します。
