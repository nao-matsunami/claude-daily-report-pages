3AI(agy/codex/claude)突き合わせ + Claude審判。確度ラベルを必ず確認すること。

3つの出力を突き合わせ、一次情報で裏を取った結果です。今日は Gemini 側にバージョン誤帰属と事実誤認が1件ずつありました。

1. Claude Code — Week 34 ダイジェスト（8/17–21、v2.1.234→v2.1.239）

/design スキル（リサーチプレビュー）

[確認済] Claude Design の artboard ワークフローを CLI と Claude Code Desktop に移植したスキル。artifacts 上に構築され、ブリーフを渡すと編集可能なアートボードのキャンバスを publish し、選んだ案を Claude が実装する。Pro/Max/Team/Enterprise、v2.1.233 以降が必須。3AI とも言及し、公式ダイジェスト本文で確認（コマンドではなく「skill」表記）。
https://code.claude.com/docs/en/whats-new/2026-w34

Concise 出力スタイル（v2.1.237）

[確認済] 前置き・実況を省いて結果から書く組み込みスタイル。作業の徹底度は Default と同等で、エラー報告・セキュリティ警告・破壊的操作の確認は全文維持。/config の Output style か ~/.claude/settings.json の {"outputStyle": "Concise"}。反映には /clear か新セッションが必要（公式に明記）。codex と Claude が一致、原文で確認。
https://code.claude.com/docs/en/whats-new/2026-w34

Remote Control がリサーチプレビュー卒業

[確認済] claude remote-control を動かしているマシンが Claude モバイルアプリ Code タブ上部に device card として表示され、そこからディレクトリを選んでセッション開始できる。
https://code.claude.com/docs/en/remote-control#start-a-remote-control-session

Other wins（一次で全項目確認）

[確認済] 以下はすべて公式ダイジェスト本文に存在:

  • ANTHROPIC_DEFAULT_MODEL（新規セッションの開始モデル。/model の選択が上書きし再起動をまたいで永続）
  • claude.ai 使用制限リセット時の自動継続（/config の Continue automatically at usage limit でオフ）
  • /permissions・/add-dir <path> を作業中に実行可、権限ルール変更は現在のターンの残りから適用
  • /goal のバックグラウンド待ちを 30分でチェックイン、アイドル中は間隔を延ばす。CLAUDE_CODE_GOAL_CHECKIN_MINUTES=0 でオプトアウト
  • SendMessage の notify_when_idle、native Windows でのクロスセッションメッセージング解禁
  • keybindingFlavor: "readline"、spellcheck 設定、GitLab MR !N バッジ（glab auth login 必要）
  • 自分のプロンプトの Markdown レンダリング、リモートからの effort 変更がローカルに適用
  • self-hosted runner の --defer-shutdown-max-min / --proxy-authorization-command|-file

[要検証] Claude が挙げた「Alt+F / Alt+D / Ctrl+Y も v2.1.239 で Bash 準拠」「auto mode で Monitor の allow ルールが保留され Monitor コマンドも審査対象に（v2.1.236）」「status.showUntrackedFiles=no の穴塞ぎ」— changelog の取得結果は要約形式で該当行が含まれず、一次確認できませんでした（存在しないという意味ではありません）。

2. Claude Code — v2.1.240 / v2.1.241 と Gemini の誤帰属

v2.1.240（8/22）/ v2.1.241（8/23）の中身

[確認済] 公式 changelog 上はどちらも "Bug fixes and reliability improvements" のみ。Claude の記述と一致。
https://code.claude.com/docs/en/changelog

GitLab MR URL 対応 / forward_user_identity

[棄却（バージョン）／確認済（機能）] Gemini は「v2.1.240/241（8/22–23）で追加」としましたが、changelog 上はどちらも v2.1.233です。機能自体は実在:

  • --worktree フラグと claude agents ビューへの GitLab merge request URL 対応（MR は !N 表示）
  • Anthropic upstream 向けのオプトイン forward_user_identity apps gateway 設定（サインイン中ユーザーの identity をヘッダで送り、gateway 背後のプロキシがユーザー別に spend を按分できる）

「npm グローバルインストールは非推奨化」

[棄却] 公式 setup ドキュメントは現在も npm 導入手順を掲載しており、非推奨・廃止の記載はありません。実際には「Native Install（curl / PowerShell）が Recommended タブ、npm は Advanced installation options 配下」という以前からの構成で、今週の変更ではありません。なお v2.1.198 以降 npm 版は Node.js 22+ を要求し、npm パッケージはネイティブバイナリを取得するだけで実行時に Node を使いません。
https://code.claude.com/docs/en/setup

[確認済] LLM ゲートウェイ / カスタム base URL 使用時のプロンプトキャッシュ修正（v2.1.237）、および Bedrock プロキシ経由の streaming fallback による二重課金修正（v2.1.239）。

6. プラットフォーム / API（8/18–8/20）

[確認済] 8/20 Python SDK v1.0 — HTTP 層が httpx → httpx2（API 互換フォーク）。http_client/Timeout/transport は httpx2 から生成、httpx にパッチするトレーシング/モックを使うなら httpx2.alias_httpx。Python 3.10+ 必須。Text Completions API、Messages の temperature/top_p/top_k、tool runner の compaction_control を削除。async の .with_raw_response は await response.parse が必要。AnthropicBedrock はリージョン未設定でエラー。

[確認済] 8/19 GA まとめ — computer use が beta 卒業（computer_toolset_20260801、バッチアクション、zoom 既定 ON、configs）／browser use tool 新設（browser_toolset_20260801）／両 toolset は Fable 5・Mythos 5・Opus 5・Sonnet 5・Opus 4.8 で利用可／Files API GA／Agent Skills・Skills API (/v1/skills) GA／Claude Enterprise 向け Admin API ユーザー管理 GA／Managed Agents の allowed_domains/blocked_domains・self-hosted sandbox への memory stores／Console session viewer 刷新。

[確認済] 8/18 Workbench → Playground に改称・刷新（旧 Workbench は 8/17 でアクセス終了済み）。
https://platform.claude.com/docs/en/release-notes/overview

[確認済] Sonnet 5 の $2/$10 per MTok が正式価格となり、9/1 予定だった $3/$15 への値上げは実施されない — Claude が「未確認」としていた項目ですが、8/10 のリリースノートに明記があり、既決の知見とも一致します。

[確認済] 8/21 Claude Security が Mythos 5 で実行可能に — Enterprise 顧客向け、追加料金なしの標準トークンレート。あわせて Defender Advantage Fund（0xDAF）で $35M 相当のクレジット、Cyber Verification Program の拡大（Opus/Sonnet でのより広い dual-use、Mythos クラスは追って）。

[確認済] 8/20「The Claude Code guide for startups」 — ルート CLAUDE.md にはアーキテクチャ規則・セキュリティ境界・non-negotiables のみ、コーディング規約はサブディレクトリの CLAUDE.md、手順は Skills、Hooks は「ライフサイクル上の固定点で allow/ask/block する hard gate」、大量データの並列分析や adversarial review は dynamic workflows でサブエージェントをファンアウト、リビルドは git worktree、非自明な書き換えは plan モード、モデルドリフト検知に golden eval set。
https://claude.com/blog/claude-code-guide-for-startups

[確認済] 8/21「The AI-Native SDLC playbook」 — Build 段階の3成果物（CLAUDE.md = 文脈知識 / Skills = 組織ポリシーの実行可能化 / Hooks = allow・ask・block の決定論的ガードレール）、intent.md を発案者の言葉のままバージョン管理して次段の入力に、監視エージェントが逸脱検知時に intent.md を作ってパイプラインに再投入、承認は成果物レビューのゲートに集約（"The loop keeps running. Human judgement stays above it."）。
https://claude.com/blog/the-ai-native-sdlc-playbook

今日の注目

  1. /design の実機確認（v2.1.233+） — Claude Design 系で今週唯一の実質的な新機能で、Claude Code から直接使える点が大きい。ただし artifacts 依存かつ「Claude がリンクを print して人間がキャンバスで選ぶ」前提のフローなので、非対話（claude -p）や定期実行で使えるかは未検証です。/fork で同じ落とし穴（実在するが非対話不可）を踏んだ前例があるため、対話・非対話の両方で1回ずつ叩いて knowledge 化する価値があります。
  1. Concise 出力スタイル（v2.1.237） — 設定1行、リスクほぼゼロ、効果が測定しやすい。定期実行ブリーフのように出力を人が読む用途ではトークンと読解コストの両方に効きます。/clear か新セッションでないと反映されない点だけ検証時に注意。
  1. v2.1.238+ への更新確認 — 長時間 interactive セッションのメモリ無制限増加修正（v2.1.238）は常駐セッションを持つ運用に直接効き、v2.1.239 でデータレジデンシーの 1.1× プレミアムがコスト表示に入りました。claude --version の確認と、コスト表示前提を置いている箇所の突き合わせは今日中にできる範囲です。
