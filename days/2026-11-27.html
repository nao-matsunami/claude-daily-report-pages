[確認済] codex だけが主張しましたが、原文で確認できました。

今日の注目

  1. Code Mode のフックは fail-open になった（2.1.329）。onFailure: "block" を付けるか点検する
  1. Skills over MCP と PreSkillShellCommand（2.1.332）

接続中の MCP サーバーが skill を配れるようになりました。Pro / Max / Ultra では既定でオンです。その skill の読み込み時に実行されるインラインシェルを PreSkillShellCommand で止められるかを実機で試し、あわせて /context で接続前後の増加量を測ると良いです。

  1. computer-use の予約名化と管理 MCP リストの挙動戻り

手元に computer-use という名前の skill やコマンドがあれば、Mac では黙って読み込まれなくなります（起動時に通知は出ます）。確認は簡単です。Desktop の allowedMcpServers が 6.6395.0 より前の挙動に戻った件は、既存の棚卸しの前提と変わった可能性があります。
