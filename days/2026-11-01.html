今日の注目

  1. claude -p の exit 0 問題の修正(v2.1.314):cron でのブリーフ収集や検証パイプラインに「出力が空なら失敗とみなす」という回避策や、exit 0 を前提にした分岐があれば、v2.1.314 以降は exit 1 で正しく失敗が分かるようになります。2.1.312 の「不正なコマンド名1件で無出力になる」修正と合わせて、ラッパースクリプトの失敗判定を見直す価値があります。
  2. Opus 4.8 fast mode の削除(11/30、期限あり):削除後はフォールバックせずエラーになります。repo 内に claude-opus-4-8 と speed: "fast" を組み合わせた箇所がないか、grep で棚卸ししておくと安全です。Opus 4.1 の retire 時の棚卸しと同じ手順が使えます。
