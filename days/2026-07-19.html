デイリーブリーフ 2026-07-19

3AI(agy/codex/claude)突き合わせ + Claude審判。確度ラベルを必ず確認すること。

3つの出力を突き合わせ、一次情報で裏取りしました。結論から言うと、今回はGeminiの捏造は少なく、むしろ「日付のズレ」と「事実の言い換えによる歪み」が主な問題でした。

1. Claude Code

v2.1.210〜v2.1.214（7/14〜7/18）

[確認済] codex/Claudeが一致し、公式changelogで確認。最新は v2.1.214（7/18） で、EndConversation ツール、長時間ツールの進捗ハートビート、Remote Control の権限確認修正、OpenTelemetry属性追加（message.uuid/tool_source）、PowerShell の UTF-16LE 修正など。Geminiはこの範囲を丸ごと取りこぼしています。
出典: https://code.claude.com/docs/en/changelog

/fork の挙動変更 → 旧挙動は /subtask に改名（v2.1.212, 7/17）

[確認済] 会話を新しいバックグラウンドセッションにコピーし claude agents に独立行を持つ。従来のセッション内サブエージェント起動は /subtask にリネーム。この「改名」はClaudeのみが指摘していましたが、Week 29公式digestで確認できました。
出典: https://code.claude.com/docs/en/whats-new/2026-w29

Artifacts が MCP コネクタを呼べる（web）

[確認済] 公開済みartifactが閲覧者自身のMCP接続経由でページ表示のたびにライブデータ取得・アクション実行が可能に。初回コネクタ呼び出し前に閲覧者の承認が入る。公開共有リンク、Team/Enterpriseのeditorロールも同時追加。Claudeのみが報告、公式で裏取れました。

スクリーンリーダーモード（CLI）

[確認済] claude --ax-screen-reader / CLAUDE_AX_SCREEN_READER / axScreenReader 設定。ターミナルUIを線形テキストに置換。Week 29の2大機能のひとつ。

暴走ループ対策の上限

[確認済] WebSearch呼び出しとサブエージェントspawnが各セッション既定200回。CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION / CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION で変更可。

その他（すべて[確認済]、Week 29 digest記載）

2分超のMCPツール呼び出しの自動バックグラウンド化（CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS）／auto modeのオプトイン不要化（Bedrock・Google Cloud Agent Platform・Microsoft Foundry、disableAutoMode で無効化可）／claude auto-mode reset／corporate launcher（CLAUDE_CODE_PROCESS_WRAPPER）／vimInsertModeRemaps／--forward-subagent-text／「Always allow」ルールのリポジトリルート保存／Bedrock等でOpus 4.8がデフォルトに／折りたたみツール要約の経過時間カウンタ。

週間利用上限 +50% プロモーション（7/19 23:59 PT終了）

[確認済] Gemini単独主張でしたが裏が取れました。Pro/Max/Team＋レガシーseat課金Enterpriseが対象。Free と消費ベースEnterpriseは対象外。Claude Code のみが対象で、Claude本体やCoworkの上限は変わりません。今日が最終日です。
出典: https://www.helpnetsecurity.com/2026/07/13/claude-code-weekly-limits-promotion-extended/

「Efficiency Bypass」v2.1.198（AskUserQuestion の60秒自動進行）

[確認済（ただし対象期間外）] Geminiが「7月初旬・未確認」としていた件は実在します。ただし出荷は 7/1（v2.1.198/199）で直近1週間の話ではありません。無告知・changelog未記載で炎上し、メンテナが「/config で露出、既定オフ、タイムアウト設定可」にすると表明済み。Geminiの「エージェントが自律進行する新機能」という書き方は、実態（撤回方向の不具合的挙動）を美化しています。
出典: https://www.olafalders.com/2026/07/17/claude-code-anatomy-of-a-misfeature/

2. Claude Cowork

Web / モバイル展開（7/7、beta）

[確認済] Gemini/Claude一致、公式ブログあり。リモートセッションがAnthropicのサーバー上で走り、全デバイスをオフラインにしてもスケジュール実行が継続。Chat と Cowork が単一ホームタブに統合、Projects と artifacts を共通化。Maxプランから順次。厳密には直近1週間より前ですが、7/13前後にロールアウトが進行中。
出典: https://claude.com/blog/cowork-web-mobile

「The work around the work」利用実態データ

[確認済・数字を訂正] Geminiの「約90%が非コーディング業務」は正しい。ただし内訳まで押さえると、5/11〜5/31の120万セッション／60万超組織の分析で、ビジネスプロセス・運用 33.4%、コンテンツ制作 16.4%、ソフトウェア開発はわずか 8.7%。
出典: https://claude.com/blog/how-people-are-using-claude-cowork

Live artifacts（Cowork）

[要検証] codex単独。Coworkで永続的・対話的なHTMLダッシュボードを作り、接続アプリやローカルファイルから最新データで更新する機能。ヘルプ記事は「今週更新」表示のみで公開日が特定できず、直近1週間の新機能かどうか確認できません。上記「Artifacts×MCPコネクタ」と機能的に近く、混同の可能性あり。
出典: https://support.claude.com/en/articles/14729249-use-live-artifacts-in-claude-cowork

今日の注目

1. Claude Code の週間上限 +50% プロモが今日 23:59 PT で終了
唯一の「期限が今日」の項目です。重い作業を回す予定があるなら今日中に。終了後は通常上限に戻るだけで、プラン・課金の変更はありません。

2. Artifacts × MCPコネクタ（Week 29の目玉）
公開したartifactが閲覧者自身のMCP接続でライブデータを引ける、というのは配布物の性質を変える更新です。「セッション時点のスナップショット」だった成果物が「生きたダッシュボード」になる。公開共有リンクとTeam/Enterpriseのeditorロールも揃ったので、社内向けダッシュボードの試作に一番手応えがあるはずです。閲覧者承認フローの挙動も含めて実機で確認する価値あり。

3. /fork → /subtask の改名（破壊的変更）
地味ですが既存ワークフローが壊れるタイプの変更です。/fork に「セッション内サブエージェント起動」を期待していたスクリプトやドキュメント、チームの手順書があるなら要修正。今の /fork はバックグラウンドセッションへのコピーで、意味が完全に変わっています。
