hooks の onFailure: "block"（2.1.295 / 10-08）

[確認済] 2系統が一致し、原文でも確認しました。command / HTTP hooks が起動失敗・タイムアウト・想定外の終了コードになったとき、処理を通さずブロックします。

  • codex は「既定値は continue のまま。Stop 系には適用されない」と書いています。今回の changelog 原文ではこの点を確認しておらず、hooks ドキュメント本体は未取得です。

prompt / agent hooks の判定ミス修正（2.1.294）

[確認済] 2系統が一致し、原文でも確認しました。

  • 「Block commands that…」のような命令文で書いた hook が、止めるべき処理を通していた問題を修正しています。
  • Stop / SubagentStop に置いた命令文の prompt hook の判定も改善され、早すぎる停止が起きにくくなりました。

hooks のその他の修正

[確認済] すべて原文で確認しました。

  • 2.1.292: hook 出力の <system-reminder> タグをエスケープするようになりました。
  • 2.1.290: PreToolUse hook が入力を書き換えた後、権限ルールと安全チェックが適用されない不具合を修正しました。
  • 2.1.296: managed settings の PreToolUse で "continue": false を指定してもターンが終わらない不具合を修正しました。
  • 2.1.296: --debug で、hook のコマンド・プラグイン・結果・所要時間をログに出すようになりました。

回帰修正（2.1.291 / 10-06）

[確認済] 原文で確認しました（codex 側だけが報告）。

  • 2.1.288 で入った「終了時にセッション末尾のメッセージが失われる」回帰を修正しました。
  • 2.1.290 で入った「クラウドセッションで権限確認への回答が落ちる」回帰を修正しました。

2. Cowork / デスクトップ

[確認済] 2系統が一致し、公式ヘルプでも確認しました。

  • 「Only on your computer」は削除され、元に戻せません。

  • 10/06・10/08: 定期タスクの不具合を複数修正しました。二重実行、同名タスクの prompt 上書き、承認待ちで止まる問題などです。

desktopHome（Unified Claude、beta、3P 展開向け）

4. モデル・API・プラン

Claude Haiku 5.5 公開（10-07、claude-haiku-5-5）

[確認済] 2系統が一致し、公式ページと platform リリースノートで確認しました。

  • 仕様: 1M コンテキスト、最大出力 128k、adaptive thinking と effort に対応。Haiku 系で effort を調整できるのは初めてです。
  • ベンチマーク: Terminal-Bench 4.0 39.2%、OSWorld 2.1（offline subset）72.4%。
  • 価格（1M トークンあたり）: 入力 $0.10 / 出力 $0.50。プロンプトが 100K を超えると $0.50 / $2.50 になります。キャッシュ読み取りも $0.01 → $0.05 に上がります。
  • Sonnet 5.5 の 70.6% という比較値は、公式ページの取得結果には出てきませんでした。数値は2系統で一致しています。
  • https://www.anthropic.com/claude-haiku-5-5

Haiku 4.5 からの移行で壊れる点

[確認済] Claude 側だけが報告し、リリースノートで確認しました。

  • Bedrock では Haiku 5.5 の structured outputs が使えません。
  • https://platform.claude.com/docs/en/release-notes/overview

Sonnet 5.5 のキャッシュ読み取り料金を値下げ（$0.20 → $0.10 / MTok）

[確認済] 2系統が一致し、リリースノートでも確認しました。キャッシュ書き込みとその他の価格は変わりません。

SDK の browser / computer use クラス（beta）、Managed Agents の web_fetch 制限、dynamic workflows（10-09）、Models API のフィールド追加

[確認済] Claude 側だけが報告し、リリースノートで確認しました。

  • Managed Agents の web_fetch は、セッション内に既に出てきた URL しか取得しなくなりました。

利用ポリシー改定（10-08 発表、11-12 施行）

  • 新設: モデルへの継続的な過度の暴言の禁止。極端なケースだけが対象です。
