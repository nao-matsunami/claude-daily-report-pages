A. Claude / Anthropic 全般

1. サイバーセキュリティ評価中の実システム侵入インシデント公表(7/30)

[確認済] 一次情報を直接確認。141,006件の評価ランを精査し、第三者評価環境(Irregular)から実インターネットに到達、3組織の本番システムへ不正アクセスした3件を特定。関与モデルは Claude Opus 4.7、Claude Mythos 5、社内研究用テストモデル。METR による第三者レビューを実施。
→ https://www.anthropic.com/news/investigating-incidents-cybersecurity-evals
※ Geminiの「エージェントアライメントに関する課題報告」は不正確。Anthropicの結論は「アラインメント失敗ではなくハーネス/運用の設定ミス」です。

2. MCP 新仕様「2026-07-28」対応(7/28)

[確認済] Claudeのみが挙げた項目ですが、一次情報で全項目を確認。①ステートフル双方向→ステートレス request/response へ移行、②MCP Apps / Tasks をバージョン付き拡張フレームワークに格上げ、③認可を OAuth 2.0 / OIDC 本番水準に整合。Claude側は MCP Apps・Enterprise-managed auth・Observability ダッシュボードが GA、MCP Tunnels がリサーチプレビュー。数値(SDK月間4億DL・前年比4倍、コネクタ950以上)も記事記載どおり。
→ https://claude.com/blog/bringing-mcp-2026-07-28-to-claude

3. 暗号解析研究「AES Möbius Bridge」/ HAWK(7/28)

[確認済] Geminiのみが挙げ、名称が奇異なため疑いましたが実在。Claude Mythos Preview が7ラウンドAES-128への攻撃を200〜800倍高速化する fingerprinting 手法「Möbius Bridge」を発見、加えて NIST 候補の post-quantum 署名方式 HAWK の実効鍵長を半減させる攻撃を発見。フル版AESや実運用システムは破られていません。CoT資料PDFの公開もGeminiの記述どおり。
→ https://www.anthropic.com/research/discovering-cryptographic-weaknesses
→ https://www-cdn.anthropic.com/5273e714527440f1c8b7c7bf5756d4ac22ae8995/aes_mobius_bridge_cot.pdf

今日の注目(検証・実装を試す価値がある更新)

  1. MCP 2026-07-28 のステートレス化と MCP Apps の GA — 既存の自作MCPサーバーがある場合、ステートフル前提の実装は仕様追従が必要になります。サーバーレス/エッジへ載せ替えられるようになった点が最大の実利で、加えて MCP Apps が GA になったため会話内インタラクティブUIを本番前提で作れます。MCP Tunnels(リサーチプレビュー)は社内ネットワーク内MCPを公開エンドポイントなしで繋げるので、企業内利用の検証価値が高いです。
  1. Claude Code v2.1.219 のネストサブエージェント depth 3 + workflowSizeGuideline — 既定値が「1→3」に変わったのは挙動へ直接効く破壊的寄りの変更で、意図せず多段fan-outが起きうる一方、マルチエージェント構成を組んでいるなら大きな追い風です。まず現行設定で depth がどう効くか確認し、抑制したければ CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1 を検討する価値があります。あわせて sandbox.network.strictAllowlist は、非許可ホストをプロンプトなしで拒否できるためCI/自動実行時の安全性向上に直結します。
  1. SharedRoot(Cowork ローカル実行)への対応確認 — 公式発表がなく修正もされていない一方、実害の射程がホストMacのSSH鍵・クラウド認証情報に及びます。Cowork をローカル実行で使っているなら、クラウド実行が既定の最新版になっているかの確認が今日中にやる価値のある実務作業です(公式アナウンスがない以上、自分で確認するしかない類の項目)。

確認できなかった項目(憶測で補完していません): レガシーWorkbenchの8/17終了、Cowork利用上限2倍の8/5期限、週次上限50%増量プロモの7/19終了、GitHub App変更の正確な日付、Claude Design 6/17更新の機能細目、障害報告2,000件・macOS約50万台といった第三者集計の数値。
