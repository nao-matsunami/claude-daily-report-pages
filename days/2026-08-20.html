テキスト透かし(watermarking)

[確認済] 3AI 一致。原文確認:2026年8月2日以降にローンチしたモデルが machine-readable marking を標準搭載、それ以前のモデルには順次追加。方式は Google DeepMind の SynthID-Text 系で「単語選択に使う乱数源」を変える。「Nothing is added to the text and there are no hidden characters.」(隠し文字・Unicode 追加ではない)。EU 限定ではなくグローバル適用(「we don't yet have a durable way to scope it by region」)。短いサンプルやコードでは検出力が落ちる。
Gemini の「ファイルの来歴メタデータ」も正しい:ヘルプ記事に「When Claude generates a supported file type, such as a .svg, .png, or .jpg, it will attach signed provenance metadata」とあり C2PA 準拠、対象は Claude Platform / Claude / Claude Code / Claude Cowork / Claude Tag / AWS・Google Cloud・Microsoft Foundry。
細部の要検証: Gemini・Claude がともに挙げた「EU AI Act 第50条(2)」という条番号は、取得した本文中に確認できなかった(EU AI Act および 2026年7月署名の EU Code of Practice への言及はある)。条番号の裏は取れていない。

今日の注目

1. v2.1.236 の auto mode 変更 —「Monitor allow ルールが棚上げされる」

notify_when_idle や ANTHROPIC_DEFAULT_MODEL の追加が目を引きますが、実運用への影響が大きいのは 「auto mode 中は Monitor の allow ルールが set aside され、Monitor コマンドが Bash と同じ審査を受ける」という変更です。auto mode 既定化(8/14)と組み合わさると、Monitor の allow ルールに依存した自動化は静かに承認待ちで詰まる可能性があります。8/14 の auto mode 既定化については既に検証済みなので、その延長として Monitor ルールの棚卸しを実機で確認する価値があります。

2. v2.1.235 の「language server 再接続でプロンプトキャッシュが全滅する」バグ修正

コストとレイテンシに直撃する修正で、アップデートするだけで効果が出るタイプ。長時間セッションで入力トークンが不自然に膨らんでいた場合、原因がこれだった可能性があります。修正前後で同じ作業のキャッシュヒット率を比較すれば効果を定量化できます。

3. Cowork の Chrome サイドパネル化(8/12)

3AI のうち Gemini だけが拾い、かつ一次情報で裏が取れた項目です。skills / plugins / connectors がブラウザで初めて動くようになり、サイドパネルで始めた作業をデスクトップ/ウェブ/モバイルで再開できます。Cowork を重視する方針であれば、既存の skills がブラウザ側でどう見えるかを実際に試す価値が高い。Max/Team は即時、Pro は数週間かけて展開。

検証で確認できなかったもの(「存在しない」ではありません): v2.1.236 の公開日、/design が今週追加されたという主張、EU AI Act の条番号「第50条(2)」、claude_code_docs_map の 8/19 更新、およびセキュリティ事案 4 件(一次確認未実施)。
