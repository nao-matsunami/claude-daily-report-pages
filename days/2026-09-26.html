今日の注目

  1. v2.1.283:サードパーティプロバイダ利用時とテレメトリ無効時の auto mode 起動、および Desktop の Code タブで auto mode が既定に
  • headless の cron でテレメトリを無効にしている場合、権限モードが知らないうちに変わる可能性があります。
  1. v2.1.282:project と local の settings で OTel 変数が無視されるようになった
  • リポジトリの .claude/settings.json などで CLAUDE_CODE_ENABLE_TELEMETRY や OTEL_LOG_* を使っていると、何も言われずに無効になります。
  • 起動時の通知と claude doctor で、棚卸しが一度で済みます。
  1. v2.1.280:Pro と Team Standard の既定モデルが Opus に変わり、Opus 5.5 の既定 effort は medium
  • モデルと effort を明示していない定期実行では、コストと品質の両方が変わります。
  • /doctor prompt-audit と合わせて、明示指定が必要かを確認するとよいです。
