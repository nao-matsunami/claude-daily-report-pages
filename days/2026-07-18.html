Claude/Anthropic 直近動向 精査レポート(基準日 2026-07-18)

1. Claude Code

v2.1.211 リリース(7/15)

[確認済] --forward-subagent-text(stream-json でサブエージェントのテキスト/思考を出力)追加、権限プレビューの制御文字無害化、メモリリーク修正。Gemini・Claude 一致、一次changelogとも整合。ただしGeminiは「7/15」、releasebot集約は「7/16」と表記差あり。
出典: Claude Code changelog / releasebot

v2.1.212 リリース(7/17)

[確認済] /fork のバックグラウンドセッション複製化、claude auto-mode reset 追加、セッション単位の WebSearch 呼び出し上限(既定200)・サブエージェント生成上限、2分超MCPツールの自動バックグラウンド化。Claudeのみ記載だが一次changelogで確認できた。
出典: Claude Code changelog

v2.1.207〜210(7/11〜14)

[確認済] Bedrock/Vertex/Foundry での Auto mode オプトイン不要化(207)、スクリーンリーダーモード(208)、worktree サブエージェントの git 誤操作修正(210)等。Claudeのみだが changelog と整合。

既定モデルを Opus 4.8 へ

[確認済] Claude Code の Bedrock/Vertex/AWS 既定モデルが Claude Opus 4.8。一次docsでも「Opus 4.8 が既定(旧4.6)」と確認。
出典: Model configuration docs

⚠️ Gemini の「週間利用制限50%増量」の帰属誤り

[要検証→部分訂正] Geminiは「Claude Code の週間利用制限50%ボーナスを7/19まで延長」と単独キャンペーン扱い。実際は Fable 5 アクセス延長に付随した措置(下記4参照)。50%増量・7/19 という数字自体は正しいが、Geminiは Fable 5 という文脈を丸ごと欠落させている。

2. Claude Cowork(Web / モバイル)

出典: claude.com/blog/cowork-web-mobile / TechCrunch

⚠️ Gemini の「Cowork 利用上限2倍キャンペーン(8/5まで)」

[要検証・疑わしい] Gemini 単独主張。裏付けが取れず、Fable 5 の増枠キャンペーンと混同した可能性が高い。確認できなかった。 数字・日付を鵜呑みにしないこと。

3. Claude Design

[確認済] 7/11〜18の枠内に新機能・仕様変更なし(両AI一致)。直近の大きな動きは 2026年6月の大型アップデート(デザインシステムインポート、Claude Code 連携、トークン消費削減、エンタープライズ向けエクスポート)。初回ローンチは 4/17。
出典: VentureBeat

⚠️ コマンド名の不一致

[要検証] Gemini は /design-sync、Claude は /design と記載。正確なコマンド名は未確認。 Gemini は「利用クォータ共通化」も主張するが裏取れず。固有名はGeminiの捏造傾向に注意。

4. モデル / プロモーション

Fable 5 アクセスを 7/19(PT 23:59)まで再延長 + 週間レート上限50%増

[確認済] 週内2度目の延長。OpenAI の新モデル(GPT-5.6、コードネーム "Sol")投入への対応。有料プランで週次上限の最大50%を Fable 5 に充当可、Claude Code の週間レート50%ボーナスも同日まで連動。Claudeが正しく捕捉、複数報道で確認。
出典: Forbes(7/13) / officechai

❌ Gemini「Claude Sonnet 5 を各サービスのバックエンドで展開(6/30発表、8/31まで特別価格)」

[棄却] 今週のフラッグシップ/プロモ対象は Fable 5、Claude Code 既定は Opus 4.8。「Sonnet 5 がバックエンド」「6/30」「8/31まで特別価格」は裏付けが取れず、Gemini の固有名・日付の捏造の疑いが濃い。 Sonnet 5 自体は実在モデルだが、この文脈の主張は誤り。
