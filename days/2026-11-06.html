1. Claude Code(重点)

v2.1.314(10/30)

  • idle compaction の対象を VS Code、Desktop の Code タブ、Bedrock/Vertex/Foundry/ゲートウェイに拡大 [cl]

[確認済] 20万トークン超の会話がアイドルになると要約が作られ、次のメッセージ時点でキャッシュが切れていればその要約を使います。テレメトリをオフにしているサブスク利用者にも適用されます。
出典: https://code.claude.com/docs/en/changelog

  • permissions.blockWritesOutsideWorkingDirectories を追加 [cl]

[確認済] Claude は「公式本文では未確認」としていましたが、2.1.314 の Added 欄に原文があります。どの権限モードでも Write/Edit/NotebookEdit が作業ディレクトリ外を拒否します。
ただし、この知見が 2.1.314 より前の版でこの設定を扱っていた場合は版数の帰属が食い違います。知見本文の版数と照合してください。

  • PreCompact hook の出力を1件あたり10,000文字で切り詰め [cl]

[確認済] 出力が巨大な hook のせいで compaction が失敗したり繰り返されたりする問題の修正です。

  • **hook の if 条件 Monitor(tail *) が Monitor ツールのシェルコマンドに一致するように** [cl]
  • headless/SDK セッションのサブエージェントのメモリ改善 [cl]

[要検証] 取得した changelog の範囲には出てきませんでした。ページが非常に長く、全文は読めていないため、存在しないという意味ではありません。

  • (参考)/design-sync のアップロード確認画面にフォルダ・プロジェクト・対象ファイルを表示 — どちらの AI も挙げていませんが、2.1.314 の原文にあります。[確認済]

[確認済] 他に effort の指定がないとき、セッションから継承する代わりにこの値を使います。

  • CLAUDE_CODE_DISABLE_ULTRATHINK を追加 / VS Code の ultrathink が xhigh で動作 [cx][cl]

[確認済] 環境変数の追加は原文で確認しました。「VS Code で xhigh」の部分は、取得範囲の原文では確認できていません。両 AI が一致しているため確認済としています。

  • /diff が大規模リポジトリで実行する Git コマンドを削減 [cx]

[確認済] 更新のたびに全リポジトリ対象の git コマンドが通常1回減り、git が遅いときは更新間隔を空けます。

今日の注目

  1. Read のスタブ廃止(2.1.317)の影響の実測。 未変更ファイルを読み直すたびに中身が返るようになったので、同じファイルを何度も読むワークフローでは消費が増えるかもしれません(まだ推測です)。HN で話題のサブエージェント要約コストと合わせ、検証パイプラインの /context や使用量を更新前後で比べる価値があります。スタブを前提にした hook やプロンプトがないかの棚卸しも必要です。
