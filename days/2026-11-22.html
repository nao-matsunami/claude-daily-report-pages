今日の注目

  1. v2.1.329 の Code Mode PreToolUse 失敗時の変更と、v2.1.328 の hook 変更（A-8・A-12）

Code Mode では、エラーになった hook が呼び出しを止めなくなり、UserPromptSubmit は実行されず、管理設定の PostToolUse も拒否済みの呼び出しでは発火しなくなりました。deny 床を hook に頼っている場合、何も言われずに防御が抜けている可能性があります。code-mode-hooks-deny-floor-impact.md を再監査し、拒否が必須の hook に "onFailure": "block" を付けることを優先してください。

  1. Desktop v6.28899.6 の「SSH ホストに 2.1.330 必須」と B-5 の保存期間変更（B-1・B-5）

どちらも更新前の対応が必要で、間に合わないと SSH セッションが開始できなくなるか、データが完全に消えます。更新を後から戻しても復旧できない種類のリスクです。

  1. v2.1.328/329/330 の compaction・セッション修正（A-1・A-9・A-13・A-14）

システムプロンプトの使い回し、出力上限での欠落、compact 直後のフリーズ、-p --continue での SessionStart 環境変数の消失、CLAUDE_CODE_FORK_SUBAGENT=0 での待機の既定化は、どれも headless の cron 実行に直接効きます。2.1.330 に更新したうえで、claude -p を使う定期ジョブを1回実機で流して確認する価値があります。
