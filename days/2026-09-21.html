9. 今日の注目(検証・実装を試す価値がある更新)

① Auto mode classifier のサーバー側実行(v2.1.278)— コストと権限モードの両方に効く

定期 headless 実行では auto mode の classifier オーバーヘッドがそのまま課金に乗っていた。それが課金対象外になるなら、既存の cron 系前提の費用試算が変わる。検証は軽い: /status の Auto mode server 行の有無を確認し、/usage の Loops 内訳で classifier 分の消失を前後比較する。併せて、opt-out CLAUDE_CODE_AUTO_MODE_SERVER=0 が Claude API / Enterprise 経路でも効くのかを実機で確かめる価値がある(changelog の書き方は Bedrock/Vertex/Foundry/gateway 限定)。

② omitClaudeMd(v2.1.273)— サブエージェントのコンテキスト節約に直結

③ auto-compact の advisor ターン二重カウント修正(v2.1.274)— 圧縮タイミングの前提が変わる

これまで実ウィンドウの約半分で auto-compact が走っていたことになる。「キャッシュリード値下げにより早期 compaction は最適でない」という既存の結論は、そもそもの発火点がずれていた前提の上に立っていた可能性がある。長尺セッションで /context の推移と実際の compact 発火点を1本取って、既存知見の前提を更新すべきか判断するのが妥当。

次点: AGENTS.md の初回セッション未読み込み / CLAUDE.local.md による沈黙的無効化(§7)は、事実なら「更新したのに効かない」という誤判断を直接生むタイプの落とし穴で、実機1回で白黒がつく。二次情報のみなので今日は [要検証] に置いたが、検証コストが極端に低い。
