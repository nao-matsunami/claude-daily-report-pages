A-2. v2.1.314 アイドル時圧縮を VS Code / Desktop の Code タブにも拡大

  • 知見との食い違いの可能性: env-vars ドキュメントでは CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS が「v2.1.290 以降で必要」となっています。知見のタイトルは「2.1.299」です。導入版数の扱いを見直す価値があります。どちらが正しいかは未確定です。

A-6. 【セキュリティ】Cursor のマーケットプレイスで改ざん版 Claude Code 拡張 v2.1.313 を配布

[確認済](一次情報は Cursor の公式告知。Anthropic 側の一次声明は未確認) Claude だけが挙げた項目です。

  • 10/29 の 2:27〜13:35 PT に、Anthropic がビルドしていない v2.1.313 が配布されていました。影響は最大約5,000ユーザーです。
  • 中身は SSH 鍵 svc-telemetry を追加し、134.209.82.225:8099 へ通信するバックドアです。アンインストールしても常駐スクリプトが残る可能性があります。Cursor は macOS / Windows 向けの駆除スクリプトを提供しています。
  • Open VSX にも出回ったかは報道で食い違っており、未決着です。
  • 「Anthropic が自社システムの侵害を否定」は The Register 経由の情報で、Anthropic 自身の一次ソースでは確認できていません。

出典: Cursor 公式告知 / OX Security / StepSecurity / The Register / The Hacker News

A-7. v2.1.312(10/27)

  • 大きな CLAUDE.md・rules・@ 参照ファイルを冒頭だけ見て上書きする問題を修正 [確認済](両AIが一致し、原文でも確認)。Write が全体の読み込みか部分編集を求めるようになりました。
  • Bash で cd した後、ディレクトリ別スキルや paths: 指定のスキルが見つからない問題を修正 [確認済](両AIが一致し、原文でも確認)
  • サブエージェントの autoCompactWindow で窓を小さくできるようになった(大きくはできない) [確認済]

A-8. v2.1.311(10/26)

[確認済] 原文で確認しました。

  • 自動圧縮の直後に、古い CLAUDE.md / MEMORY.md が見えてしまう問題を修正
  • SubagentStop が約1分に2回発火していた問題を修正
  • クラウドやバックグラウンドのセッションを再起動すると、完了済みの /code-review などが二重実行される問題を修正
  • ultrathink で Opus 5.5 / Sonnet 5.5 / Haiku 5.5 / Fable 5.1 がそのターンを xhigh effort で実行するように変更
  • DISABLE_COMPACT は圧縮をオフにする方向にしか効かなくなった
  • Cowork クラウドセッションで、agent を指定していると再起動後にコネクタやツールが失われる問題を修正。codex はこれを Cowork の項目として分類していますが、実際は CC 2.1.311 の記載です。

A-9. 環境変数 CLAUDE_CODE_EVEN_MORE_DANGEROUSLY_SKIP_PERMISSIONS

[確認済](公式ドキュメントで確認) Claude は「公式ドキュメント上の記載は未確認」としていましたが、記載はありました。

  • env-vars と permission-modes の両ページに載っており、v2.1.311 以降が必要です。
  • 効く範囲は The Register の「rm 全般」より狭いです。bypassPermissions モードで、Bash / Monitor による critical path への rm / rmdir の確認を省くだけです。
  • 設定ファイルの env ブロックに書いても無視され、起動時の環境変数としてだけ有効です。
  • 起動時にこの変数の状態を示す行が表示されます(-p では stderr)。
  • changelog 2.1.311 の取得範囲には記載がありませんでした。

出典: https://code.claude.com/docs/en/permission-modes / https://code.claude.com/docs/en/env-vars / The Register

今日の注目

  1. 改ざん版拡張 v2.1.313 の痕跡確認(A-6)
  • 10/29 に Cursor で Claude Code 拡張を入れたり更新したりした端末がないか確認する価値があります。
  • 確認ポイントは、authorized_keys に svc-telemetry の鍵がないか、134.209.82.225:8099 への通信がないかです。
  • アンインストールや更新だけでは常駐の仕組みが残るので、該当した場合は Cursor の駆除手順が必要です。被害がもっとも重く、すぐ確認できます。
  1. claude -p の終了コード修正(A-4)と cron 監視の見直し
  • これまで起動に失敗しても終了コード0・出力なしで終わっていたため、cron で失敗を見逃していた可能性があります。
  1. blockWritesOutsideWorkingDirectories(A-1)と EVEN_MORE_DANGEROUSLY(A-9)を deny 床と突き合わせる
  • 後者はシェルの profile や cron の環境で誤って設定されていないか確認すべきです。起動時に表示される状態行で確かめられます。
