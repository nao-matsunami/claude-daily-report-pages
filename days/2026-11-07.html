Desktop v4.16336.0(11/3)と v4.23118.0(11/5)。同梱の Claude Code はどちらも 2.1.317

[確認済] Claude だけが挙げた項目で、Cowork changelog 原文で確認しました。主な内容は次のとおりです。

  • プロジェクトページの Chat / Cowork 切り替えを廃止。
  • Code セッションに Monitor ツールを追加。監視中のコマンドに新しい出力が出るたび、誰も入力しなくてもターンが始まる。無効にするには disabledBuiltinTools に Monitor を指定する。
  • ワークツリー作成時に post-checkout フックを実行しなくなった。.env などのコピーには .worktreeinclude を使う。
  • プロジェクトの MCP サーバーやローカル MCP サーバーが、最初のターンの後に切断される問題を修正。
  • プロジェクトに属さない定期 Cowork タスクが、メモリを読めるようになった(保存はしない)。
  • プラグイン自身のコネクタへのサインインを追加。
  • Terminal / Browser / iOS Simulator のペインに最小化ボタンを追加。
  • アプリを新しいデザインに更新。
  • 引用符で囲んだパスだけの PreToolUse / PermissionRequest フックは、Git for Windows がない PC で呼び出しをブロックするようになった。

https://claude.com/docs/cowork/changelog

今日の注目

  1. 無人実行の止まりを防ぐ設定を cron の claude -p に入れる(2.1.319 / 2.1.318)
  • permissions.denyInsteadOfPrompting を使えば、許可プロンプトでのハングを拒否に変えてターンを続けられます。
  • どちらも一次情報で確認済みで、すぐ試せます。
  1. auto mode のテレメトリオフ時の挙動変更(2.1.319)と、既存の知見の照合
  • テレメトリや feature flag をオフにしている環境、またはゲートウェイ経由の環境では、組み込み分類器へのフォールバックがなくなり、「確認」か「拒否」になります。
  • 無人実行では、これが止まる原因になる可能性があります。
  1. Message threads ベータ(API)
  • 長いエージェントループで、リクエストのサイズと TTFT を減らせます。
  • 期限は5分で、プロンプトキャッシュの5分 TTL と同じ長さです。既存のキャッシュ前提の知見とどう組み合わさるかは、公式ノートからは読み取れません。
  • TTFT の改善幅と料金は公式に載っていないので、自分で測るしかありません。
