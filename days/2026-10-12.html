Claude/Anthropic 直近の動き 精査結果（対象: 2026-10-05〜10-12）

前提: 収集元は codex と Claude の2つだけです。一致していることは確度の参考にとどめ、主要項目はすべて一次情報で確かめました。参照した一次情報は、Claude Code changelog、Platform release notes、Haiku 5.5 発表ページ、Newsroom、support.claude.com、Cowork/Desktop changelog です。
注意: Claude Code changelog は約105万字あり、そのうち対象版を含む先頭10万字だけを読みました。

[確認済] サブエージェントを呼ぶたびに effort を指定できるようになりました。2つのAIの記述は一致し、changelog でも確認しました。
出典: https://code.claude.com/docs/en/changelog

Anthropic API での既定 Haiku が Haiku 5.5 に（v2.1.293, 10/7）

[確認済] claude-haiku-5-5 が既定の Haiku モデルになりました。Haiku を指定しているサブエージェントは、モデル・費用・挙動が変わります。
出典: 同上

Bash で単一ファイルを読んだときに、入れ子の CLAUDE.md とパス別 rules が読み込まれない不具合を修正（v2.1.293）

[確認済] Read を使わず cat/head/tail/sed -n/grep で読んだ場合に、これらが適用されない問題が直りました。2つのAIで一致しています。
出典: 同上

compaction 前の自分の行動を「完了済み」と誤認する不具合を修正（v2.1.293）

[確認済] compaction 後に、終わった作業を取り消したりやり直したりする問題が直りました。Claude だけが挙げていましたが、changelog で確認しました。

指示文で書いた prompt/agent フックの判定を修正（v2.1.294, 10/8）

[確認済] 「Block commands that...」のような指示文のフックが、ブロックすべき操作を通してしまう問題が直りました。Stop/SubagentStop での判定も改善されています。2つのAIで一致しています。

command/HTTP フックに onFailure: "block" 追加（v2.1.295, 10/8）

[確認済] 既定値は "continue" で、つまり fail-open です。hooks ドキュメントに明記されていました。

  • 失敗とみなされるもの: 起動できない、exit code が 0/2 以外、HTTP エラー、timeout、出力が不正。
  • 設定しても効かないもの: Stop / SubagentStop / TaskCompleted / TeammateIdle フック、async のフック。

出典: https://code.claude.com/docs/en/hooks

autoCompactWindow と CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL 追加（v2.1.296, 10/9）

[確認済] サブエージェントの定義で、親とは別に auto-compact を始める閾値を決められるようになりました。新しい環境変数を使うと、ワークフロー内のエージェントだけを同じモデルに揃えられます。2つのAIで一致しています。

claude.ai から同期した skills の再ダウンロード問題を修正（v2.1.296）

[確認済] 複数セッションで設定ディレクトリを共有していると、インストールが終わらず同期のたびに再ダウンロードされる問題が直りました。

非 UTF-8 ファイルの Edit で文字が壊れる問題を修正

[確認済]（ただし版数を訂正）Shift-JIS、GBK、Windows-1252 のファイルでは、壊す代わりに編集を拒否するようになりました。codex は v2.1.296 としていましたが、changelog では v2.1.295 です。

その他、Claude だけが挙げ、changelog で確認できた項目

[確認済]

今日の注目

  1. onFailure: "block"（v2.1.295）を安全ゲート用のフックに設定するか判断する
  • 既定は continue（fail-open）なので、スクリプトのパスを間違えたりクラッシュしたりすると、何も止めずに素通りします。
  • deny を補う PreToolUse フックがあれば、明示的に block にする価値があります。
  • ただし Stop 系のフックや async のフックでは効かないので、棚卸しの際に分けて扱う必要があります。
  1. Haiku 5.5 への既定切り替え（v2.1.293）と 4.5 からの破壊的変更を棚卸しする
  • model: haiku のサブエージェントや API 呼び出しで、temperature や budget_tokens、prefill を使っていると 400 エラーになります。
  • 100k を超えると料金が5倍になります。opus-5-5-breaking-params-repo-audit の手順を流用できます。
  1. 入れ子 CLAUDE.md の読み込み修正（v2.1.293）と autoCompactWindow（v2.1.296）を確かめる
  • ヘッドレス実行のエージェントが Bash でファイルを読む運用なら、今まで効いていなかった rules が効き始めます。挙動が変わる可能性があります。
  • 長く動くサブエージェントには、autoCompactWindow で早めの compaction を試す価値があります。
