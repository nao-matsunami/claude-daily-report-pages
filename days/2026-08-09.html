3AI(agy/codex/claude)突き合わせ + Claude審判。確度ラベルを必ず確認すること。

3AIの出力を突き合わせ、主要項目を一次情報で確認しました。以下、確度ラベル付きの統合結果です（対象期間 2026-08-01〜08-09）。

A. Claude Code

A-1. auto mode が Pro / Max / Team の既定に（8/7発表・8/14適用）

[確認済] — codex単独主張だったが一次確認できた。Pro/Max/Team の新規セッションは 2026-08-14 から auto mode 既定（Enterprise は当面 opt-in）。classifier のオーバーヘッド課金は 8/7 付で停止。公式は根拠として「ユーザーは権限要求の97%を承認していた」「1,053名の有料テスターで危険コマンドの89%を auto mode がブロック、人間レビューは13.6%」を提示。既存の default 固定済みユーザーは影響なし。
https://claude.com/blog/auto-mode-default-in-claude-code

A-2. auto mode の本番運用事例（8/7）

[確認済] — codex が挙げた固有名 Nuro / Gusto / Garner Health は3社とも正確。Nuro は再帰削除を deny + PRレビューは対話モード、Gusto/Garner は Slack・メール送信を auto 承認から除外、Gusto は MCP を governed proxy 経由に。
https://claude.com/blog/auto-mode-in-production

A-3. v2.1.226 / v2.1.225（8/8）

[確認済] — 2.1.226 は信頼性修正のみ。2.1.225 は gateway spend-limit 表示（上限額・リセット時刻・運用者メッセージ）、claude agents の workspace trust プロンプト、長命 CLAUDE_CODE_OAUTH_TOKEN が401で短命トークンに置換される不具合修正、macOS の MCP OAuth 401バースト修正、大規模compact後の Remote Control 再開修正。
https://code.claude.com/docs/en/changelog

A-4. クロスセッション SendMessage / セルフホスト runner（v2.1.224, 8/7）

[確認済] — 専用ドキュメントも一次確認。送るのはテキストのみ（会話履歴・ファイルは送らない）、同一マシン内は per-session ソケット経由で Anthropic サーバーを通らない、他マシン／web は Remote Control 経由で返信のみ可。受信メッセージは権限承認も設定変更もできず、本文中のスラッシュコマンドは実行されない。macOS/Linux のみ（native Windows 非対応）、Bedrock/Vertex/Foundry 非対応。制御設定は crossSessionInbound / isolatePeerMachines / dialogExpiry。
https://code.claude.com/docs/en/cross-session-messaging

A-5. サブエージェント 200体スポーン上限の撤廃

[要検証（事実は確認済／版番号が未確定）] — 「200体上限の撤廃（同時実行数・深さ制限は継続）」自体はチェンジログで確認できた。ただし codex と Claude は v2.1.224、当方の取得では v2.1.222 の項目として出ており、どの版かは決着していない。
https://code.claude.com/docs/en/changelog

A-6. セルフホスト環境 public beta（8/6）

[確認済] — Team / Enterprise 向け、既定オフ、ZDR 組織は利用不可。runner は fixed / on-demand の2モード。リポジトリ・ビルド成果物・シークレットは自社インフラに残るが、プロンプト／応答／ツール結果は推論のため Anthropic に送信され、トランスクリプトは保存される（ここは誤解しやすいので明記）。
https://claude.com/blog/run-claude-code-sessions-on-your-own-compute

A-7. v2.1.223（8/6）

[確認済] — Bash権限チェックのバイパス修正（不可視Unicode/タブ詰め）、ワークフローの動的 import サンドボックス脱出修正、エージェント定義 bypassPermissions が組織ポリシーを無視する穴の修正、strictKnownMarketplaces の owner/* ワイルドカード、サブエージェントモデル制限時の警告、/review → /code-review エイリアス化＋レベル再利用。CLAUDE_CODE_DISABLE_1M_CONTEXT が全1Mモデルを200Kに抑制。

A-8. v2.1.222（8/4）

[確認済] — worktree 分離セッションがメインチェックアウトに破壊的 git を実行できた問題の修正、PreToolUse auto-allow がバックグラウンドタスクでツール制限をバイパスしていた問題の修正、Remote Control 自動起動をリポジトリローカル設定から有効化不可に、ultraplan 機能の削除（当初は当方の取得に出ず、DevelopersIO の 2.1.222 解説で裏取り）。

A-9. v2.1.221（8/4）

[確認済] — VS Code の Focus view（Ctrl+Alt+F）、Linux/WSL のサンドボックス資格情報 mode: "mask"、zsh [[ ]] / PowerShell 引用符パスの権限バイパス修正、auto mode の権限チェックのプロンプトキャッシュコスト削減、/fork が独自 worktree を作成、claude-api スキルの prompt-audit。
※ Claude は /code-review ultra 導線を 2.1.223 に置いたが、当方の取得では /ultrareview エイリアス追加は 2.1.221。どちらの版かは未確定（機能の存在は確認済）。

A-10. Reddit のトークン消費増・上限体感悪化の報告

[要検証] — codex の整理どおり体感報告のみ。公式の usage limit 変更発表は確認できなかった（「変更がない」ことの確認ではない）。

B. Claude Platform / API

B-1. Managed Agents に session budget / advisor / inference_geo / GitHubスキル読み込み（8/7）

[確認済] — 4項目すべて一次リリースノートで確認。予算到達で budget_reached stop reason で一時停止、予算の変更・削除で再開。advisor は multiagent roster に {"type": "advisor"} として設定し、エージェント自身と同等以上の能力のモデルをターン中に参照。inference_geo はエージェント作成時またはセッション単位で上書き。リポジトリを mount するとルート .claude/skills を開始時に自動検出。
https://platform.claude.com/docs/en/release-notes/overview

B-2. Inference hooks（Enterprise beta, 8/5）

[確認済] — claude.ai / Cowork / Claude Code をまたぎ、各プロンプトを推論前に組織の AI セキュリティサーバーの allow/deny 判定で保留。リクエストは署名され、拒否は Activity Feed に記録。今週 Cowork に効く唯一の一次変更がこれ。
