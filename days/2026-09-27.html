今日の注目

  1. 2.1.280 の effort 引き継ぎ変更と、Opus 5.5 のデフォルト medium（headless の定期実行への影響）
  • 保存済みの /effort が新モデルに効かなくなり、原文には「headless と SDK で起動時のデフォルトeffortを維持しない」ともあります。
  • その結果、cron で動かしている claude -p が、意図せず medium の Opus 5.5 で動いている可能性があります。
  • 手元の実行設定でモデルIDと effort を明示しているか確認する価値があります。
  1. **2.1.282 の Skill(anthropic-skills:) / Skill(claude-ai:) allow ルールの範囲縮小**
  • 収集には入っていなかった、権限まわりの変更です。
  • これらのルールでローカル skill を許可しているつもりだった場合、確認プロンプトで止まったり、auto mode の判定に回ったりする可能性があります。
  • 過去の permissions 棚卸しと同じ流れで、すぐ確認できます。
  1. auto mode のサーバー側 classifier の適用条件（2.1.278 と 2.1.282 の差）
  • 2.1.282 の変更は「テレメトリーがオフのときの API 直接接続」に限られます。
  • 収集は版数も条件も取り違えていたので、headless の cron がどちらの classifier で動いているかを /status の「Auto mode server」の行で実際に確認しておく価値があります。
