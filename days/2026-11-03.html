A-2. v2.1.316 のその他の変更
[確認済] changelog 原文で確認しました。

  • CLAUDE_CODE_DISABLE_ULTRATHINK を追加(codex のみが言及)
  • /diff で走る git コマンドが減った
  • 未知の /model <id> を指定したときに、auto-compact が 200K を前提にする旨の警告が出るようになった
  • PowerShell hook の不具合を修正。コマンドが型キャスト・param・using・属性で始まると、exit 2 でも処理を止められていなかった

CLAUDE_CODE_DISABLE_ULTRATHINK は、env-vars ページで読めた範囲には載っていません。ドキュメントが追いついていないのかは確認できていません。
出典: changelog

A-3. サブエージェントのモデル継承の修正(v2.1.316)
[確認済] 2系統が一致しています。バックグラウンドなどで起こされた子エージェントが、継承したモデルからメインのモデルに戻ってしまう問題の修正です。changelog の該当範囲で、この行の原文までは読めていません。ただし2系統の記述は一致しています。
出典: changelog

A-4. idle compaction を VS Code と Desktop の Code タブに拡大(v2.1.314 / 10/30)
[確認済] changelog 原文で確認しました。

  • 200K トークンを超える会話が放置されると要約される
  • プロンプトキャッシュが切れていれば、次のメッセージでその要約が使われる
  • テレメトリをオフにしている契約者にも適用
  • Bedrock / Vertex / Foundry / LLM ゲートウェイでも、1時間キャッシュが有効なら動く
  • idleCompaction: false で無効化できる。CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS で閾値を変えられる(既定 200000、下限 100000、v2.1.290 以降)。どちらも settings-reference / env-vars に記載あり

出典: changelog、https://code.claude.com/docs/en/env-vars
