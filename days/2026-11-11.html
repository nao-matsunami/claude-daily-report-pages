A. Claude Code

A-1. v2.1.322：Vertex で fast mode に対応

[確認済] global / us / eu リージョンで fast mode が使えるようになりました。Vertex に拒否された場合は標準速度に戻ります。両AIの記述が一致し、changelog 原文でも確認しました。
出典: https://code.claude.com/docs/en/changelog

A-2. v2.1.321：Fable 5.2 を追加し、Fable の既定にした

[確認済] claude-fable-5-2 が追加され、「既定の Fable モデル」になりました（11/9）。ただし、Claude 側の「このバージョン以上が必要」という最低要件は changelog に書かれておらず、一次確認できませんでした。「Fable の既定」は Fable 系の中での既定という意味です。Claude Code 全体の既定モデルという意味ではありません。
出典: 同上

A-3. v2.1.321：コンテキスト・サブエージェント・読み込みまわりの修正

[確認済] 原文で確認できた修正は次のとおりです。

  • ツール定義のトークン数を多めに見積もる問題
  • 1,000文字を超えるバックグラウンド通知を先頭と末尾だけにする変更
  • 大きなファイルを1行ずつ読み続けるとメモリが増える問題
  • git stash や worktree 移動のあと skills / commands / agents が消えたままになる問題
  • fast mode が使えないとき、まず同じモデルの標準速度を試すようになった
  • headless で .claude/skills を自動再読込（CLAUDE_CODE_PLUGIN_DIR_WATCH=0 で無効化）
  • claude remote-control --settings <file> の追加

codex が挙げた「圧縮時にバックグラウンドエージェントの報告が消える／一括投入されすぎる」修正は、取得した要約の中では個別に確認できていません。
出典: 同上

A-4. v2.1.321：hooks の修正と Cowork cloud の PostToolUse 仕様変更

[確認済] 次の3点を原文で確認しました。

  • PreToolUse で、別 hook の defer が先に終わると ask が消える問題を修正
  • 大きな hook 出力が別 hook の出力ファイルを指す問題を修正
  • Cowork cloud では PostToolUse hook で AskUserQuestion の回答や ExitPlanMode の計画を置き換えられなくなった（Claude は元の内容を読みます）

出典: 同上

A-5. v2.1.319（11/6）：denyInsteadOfPrompting・MCP tasks・/context・/tasks

[確認済] 次を確認しました。

  • permissions.denyInsteadOfPrompting：許可待ちになるはずの呼び出しを拒否し、ターンを続ける
  • MCP tasks：長いタスクは自動でバックグラウンドに回る（CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND / CLAUDE_CODE_DISABLE_MCP_TASKS=1 で制御）
  • /context：各リストは上位10件だけ。表示用グリッドが後のターンにも送られていた不具合を修正
  • /tasks に「Earlier in this session」行を追加
  • /clear でバックグラウンドエージェントが止まる問題を修正
  • /claude-api latency-optimize を追加

出典: 同上

A-6. v2.1.319：self-paced /loop の終了条件変更と auto mode 拒否時の終了コード 1

[確認済] /loop は、再スケジュールせずにターンが終わると停止するようになりました（CLAUDE_CODE_LOOP_KEEPALIVE=1 で旧挙動）。auto mode が安全確認できずに拒否されたとき、claude -p は終了コード 1 を返します。
出典: 同上

A-7. v2.1.319：sandbox 時の配下 .claude/skills の読み込み

[確認済] Bash sandbox がオンのとき、配下フォルダの skills はそこで起動するか /cd した場合だけ読み込まれます。2.1.321 では ~/.claude/plugins 配下でも読み込まれなくなりました。
出典: 同上

A-8. v2.1.318（11/4）：3分でバックグラウンド化・ログイン期限警告

[確認済] 次を確認しました。

  • バックグラウンドのサブエージェントは、3分を超えたシェルコマンドを全プロバイダでバックグラウンドに移す
  • 読み込み前の MCP ツールを呼ぶと入力スキーマが返る
  • claude -p のテキスト出力で、ログイン期限の10日前から stderr に警告
  • claude auth status に loginExpiresAt を追加

出典: 同上

A-9. v2.1.317（11/3）：Read の unchanged スタブ廃止など

[確認済] 次を確認しました。

  • 変更のないファイルを読み直しても全文が返るようになった（そのぶんコンテキストを消費）
  • 大きな CLAUDE.md が変わったあと、compaction 直後に「Prompt is too long」になる問題を修正
  • Agent SDK の hook callback に onFailure: "block" を追加
  • 別モデルで動くサブエージェントは、そのモデル用に保存された effort を使う
