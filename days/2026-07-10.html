デイリーブリーフ 2026-07-10

3AI(agy/codex/claude)突き合わせ + Claude審判。確度ラベルを必ず確認すること。

3つの出力を突き合わせ、一次情報で裏取りしました。結論を先に言うと、事前の想定が外れました。「Gemini が捏造していそう」と疑った項目(J-space、Hidden Marker、Claude for Government)は全て実在し、逆に唯一数字が崩れたのは Claude(自分)が拾ってきた VentureBeat 由来の利用率パーセンテージでした。

1. Claude Code / Cowork / Claude Design(重点項目)

Cowork が Web / モバイルに展開

[確認済] 7月7日、デスクトップ専用だった Cowork が Web とモバイルに拡大。Max プランから数週間かけてロールアウトし、リモート実行ベータでセッションとファイルがアカウント側に保存されるため、端末を閉じてもスケジュールタスクが継続します。3AI 全て一致、公式ブログとリリースノートで確認しました。
出典: https://claude.com/blog/cowork-web-mobile / https://support.claude.com/en/articles/12138966-release-notes

Cowork の利用上限倍増キャンペーン(8月5日まで)

[確認済] Claude のみが「未確認」として挙げていましたが、公式ブログ本文に "doubled Cowork usage limits through August 5" の記載を確認しました。格上げします。
出典: https://claude.com/blog/cowork-web-mobile

Cowork の用途内訳「業務プロセス 33.4% / コンテンツ制作 16.4%」

[棄却] 公式ブログが述べているのは「Cowork 利用の 90% 超がソフトウェア開発以外」「business operations と content creation で全体のおよそ半分」という粒度で、小数第一位までの内訳は存在しません。VentureBeat 記事経由の数字で、一次情報と整合しません。この 2 つの数字は使わないでください。
出典: https://claude.com/blog/cowork-web-mobile

Chat と Cowork のインターフェース統合

[確認済] 7月7日、プロジェクトと artifacts を Chat / Cowork の共通ホームから扱えるように変更。Gemini と codex が一致し、リリースノートにも該当記述があります。
出典: https://support.claude.com/en/articles/12138966-release-notes

Claude Code / Cowork が Claude for Government Desktop でパブリックベータ

[確認済] 7月7日付の公式ブログを直接取得して確認しました。FedRAMP High 認定環境で提供され、ハッシュチェーン化された監査ログ、部局単位の予算上限、SCIM グループマッピングによるレート制限が付きます。Gemini のみが挙げた項目ですが、日付・内容とも正確です。 Claude は「発表日を一次ソースで確認できていない」として保留していましたが、確認できました。
出典: https://claude.com/blog/bringing-claude-code-and-claude-cowork-to-government

2. Claude / Anthropic 全般

Reflect(月次リカップ)ベータ公開

[確認済] 7月9日、Settings > Reflect で扱ったトピック・最も活動的だった日・ピーク時間帯を可視化する機能がベータ提供開始。休憩リマインダーと quiet hours も追加されました。Free / Pro / Max、Web とデスクトップが対象で、メモリ機能の有効化が条件です。3AI 一致 + リリースノートで確認。Gemini が挙げた「4D AI Fluency Framework(委譲・記述・識別・勤勉)」による分類も報道で裏が取れました。
出典: https://support.claude.com/en/articles/12138966-release-notes / https://techcrunch.com/2026/07/09/anthropics-new-claude-feature-is-quietly-selling-you-on-ai/

デュアルユース知識の「オフスイッチ」研究(AE Studio と共同)

[確認済(内容)/ [要検証](日付)] 手法名は GRAM(Gradient-Routed Auxiliary Modules) で、Transformer の各層に追加ニューロンをデュアルユース分野ごとのモジュールとして持たせ、モジュールを削除すればその知識を学習しなかったかのように振る舞わせます。50億パラメータのモデルでサイバーセキュリティ・ウイルス学・核物理・ニッチなプログラミングを対象に検証済み。ただし本番モデルには未適用の予備的研究です。Gemini は 7月8日としていますが報道は 7月9日付が多く、日付は詰め切れていません。Gemini が手法名 GRAM に言及していない点は情報の欠落です。
出典: https://www.anthropic.com/research/off-switch-dual-use

J-space(Jacobian space)論文

[確認済] 7月6日公開。Jacobian lens(J-lens)で浮かび上がる活性化の疎な部分空間が Global Workspace Theory の「グローバル・ワークスペース」のように振る舞う、という解釈可能性の論文です。Gemini 単独の主張だったため最も捏造を疑いましたが、実在します。 ただし Gemini の要約は「発見した」と断定的に書きすぎで、原論文はネットワーク中間ブロックにのみ現れ活性化分散の約 10% 以下しか説明しないという限定条件を置いています。この留保は重要です。
出典: https://transformer-circuits.pub(および https://thezvi.substack.com/p/no-space-like-j-space)

Claude Code の「隠しマーカー」トラッキング削除

[確認済] Gemini が「未確認扱い」としていましたが、Anthropic エンジニア Thariq Shihipar 氏が X 上で公に認めています。Claude Code のシステムプロンプトに、タイムゾーンが Asia/Shanghai または Asia/Urumqi の場合に日付行(Today's date is ...)を Unicode で符号化した隠しマーカーに変える処理が仕込まれていました。3月に無断転売とモデル蒸留対策の「実験」として導入され、開発者 Thereallo 氏の発見を受けて削除、PR はマージ済みです。Gemini の「複数メディアの報道」という位置づけは過小評価で、実際は当事者が認めています。
出典: https://www.malwarebytes.com/blog/news/2026/07/claude-codes-hidden-tracker-was-an-experiment-says-anthropic / https://decrypt.co/372977/anthropic-removes-hidden-claude-code-tracker-privacy

今日の注目

1. Claude Code v2.1.200 のデフォルト権限モード変更(最優先)
AskUserQuestion の自動継続が無効化され、デフォルト権限モードが CLI・VS Code・JetBrains 揃って "Manual" になりました。既存の CI パイプラインや headless 実行、自動化スクリプトが「勝手に進んでくれる」前提で組まれている場合、この 2 つの変更だけで無言で止まります。他のどの項目よりも既存資産を壊す可能性が高く、今日確認すべきです。

2. v2.1.202 の Dynamic workflow size と v2.1.205 の auto モード安全策
/config の Dynamic workflow size でワークフローのエージェント数を制御できるようになり、workflow.run_id / workflow.name の OpenTelemetry 属性も付きました。マルチエージェント実行のコストを初めて実測して絞り込めます。あわせて 2.1.205 で auto モードが未解決変数への rm -rf 前に確認を取り、バックグラウンドタスクの通知が「人間の承認は発生していない」と明示するようになりました。エージェントに広い権限を与えて運用しているなら、この 2 つは挙動を体感で確かめておく価値があります。

3. Cowork の Web / モバイル展開と上限倍増(期限あり)
リモート実行ベータにより端末を閉じてもスケジュールタスクが走ります。8月5日まで利用上限が倍のキャンペーン中で、これだけが期限付きです。Max プランから順次ロールアウトなので、対象なら重いタスクを試すのは今のうちです。

3AI の傾向についての所見

今回に限っては、指示にあった「Gemini は数字や固有名を捏造する傾向」は観測されませんでした。 Gemini 単独主張の 4 項目(J-space、Hidden Marker、Claude for Government、VS Code 1.128)は全て実在し、他 2 つが取りこぼしていた情報です。ただし Gemini には別種の弱点がありました。出典が anthropic.com トップページのような粒度の粗い URL ばかりで検証コストが高く、GRAM という手法名を落とし、J-space の限定条件(中間層のみ・分散の約 10% 以下)を落として断定的に書いています。固有名を作るのではなく、固有名と留保条件を落とす方向の誤りです。

逆に、唯一一次情報と矛盾したのは Claude(自分)が VentureBeat 経由で拾った「33.4% / 16.4%」でした。Claude 自身が未確認と明記していた点は機能していますが、次回以降、疑いの重み付けは「どの AI か」ではなく「一次情報から何ホップ離れているか」で置くべきです。
