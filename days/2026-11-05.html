前提: 入力は codex と Claude の2系統だけです。「2系統一致」は独立した2件の確認とまでは言えないため、[確認済] は原則として今日私が一次情報（changelog・リリースノート・公式記事）を直接開いて照合できたものに限りました。一致しただけで一次照合できていないものは、その旨を書いています。

Claude Code（重点）

[確認済]（Claude のみ／一次）
Write・Edit・NotebookEdit は、どの権限モードでも作業ディレクトリ外のパスを拒否します。changelog の原文で確認しました。
出典: https://code.claude.com/docs/en/changelog

v2.1.314：VS Code と Desktop の Code タブに idle compaction

[確認済]（2系統一致／一次）
200K トークンを超えて放置された会話を要約し、プロンプトキャッシュが切れていれば次のメッセージでその要約を使います。

  • Claude が補足した「ターミナル版は約54分で発動」「idleCompaction: false で無効化」は、今日 changelog から引けませんでした → [要検証]。上の knowledge で決着済みかどうかは要照合です。
  • 関連修正（v2.1.318）: 要約ではない返答で会話が置き換わる不具合の修正は原文で確認しました。

v2.1.314：多数のサブエージェントを使う headless／SDK のメモリ改善

[確認済]（codex のみ／一次）
親セッションが、各サブエージェントのツール結果をターン終了まで保持しなくなりました。

v2.1.314：その他の修正

[確認済]（一次）

  • 管理者が effort に上限を設定している場合の「Invalid effort level」連続エラーを修正。上限まで下げて再試行します。
  • FORCE_HYPERLINK=false の意味が逆だった不具合を修正。
  • claude -p が起動失敗時に exit 0 で何も出さずに終わる問題を修正。エラーを出して exit 1 になります。

v2.1.316：CLAUDE_CODE_SUBAGENT_EFFORT と CLAUDE_CODE_DISABLE_ULTRATHINK

[確認済]（SUBAGENT_EFFORT は2系統一致、DISABLE_ULTRATHINK は Claude のみ／一次）

  • CLAUDE_CODE_SUBAGENT_EFFORT: 他で指定がないとき、サブエージェントの effort をセッションから引き継がずにこの値にします。
  • CLAUDE_CODE_DISABLE_ULTRATHINK: ultrathink キーワードを無効化します。
  • 同じ版で、gateway の pooled group budget（グループで共有する月次予算）が追加されました。
  • 同じ版で、Team／Enterprise のサーバー管理設定が承認プロンプトなしで適用されるようになり、検証に通らない保存コピーは拒否されます。

v2.1.317：親と別モデルのサブエージェントは、そのモデル側の effort を使う

[確認済]（codex のみ／一次）
原文は「that model's saved effort level or its default, instead of the session's」。対象はサブエージェントと teammates です。

v2.1.317：Agent SDK の hook コールバックに onFailure: "block"

[確認済]（2系統一致／一次）
コールバックが失敗したとき、操作を通さずに止めます。

v2.1.317：Read ツールの「前回の Read 以降ファイルは未変更」省略表示を廃止

[確認済]（Claude のみ／一次）
未変更のファイルを再読込しても全文が返ります。コンテキスト消費が増えるという点は Claude 自身が推測と明記しており、一次情報には書かれていません。

v2.1.317：アカウントのメールアドレスを外部に送るツール呼び出しの事前確認／claude -p の exit code 修正

[確認済]（Claude のみ／一次）

  • Web／シェルのツール呼び出しがアカウントのメールアドレスをネットワークに送る前に確認するようになりました。
  • changelog には「Full NFS exports may be missed」という但し書きがあります。

v2.1.318：mod の $.model.fork に effort／claude auth status に loginExpiresAt

[確認済]（Claude のみ／一次）

  • effort オプションで、軽い作業をセッションの effort に関係なく low で動かせます。
  • claude -p の JSON 結果にも credential_expires_at が入ります（Claude の出力にはなかった点）。

v2.1.318：バックグラウンドのサブエージェントは3分でシェルをバックグラウンド化（全プロバイダ）

[確認済]（2系統一致／一次）
