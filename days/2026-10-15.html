A. Claude Code（重視）

A-1. idle compaction（v2.1.299, 10/14）
[確認済] 両AIが一致し、一次情報も原文で確認しました。20万トークン以上の会話を約54分放置すると、1時間のプロンプトキャッシュが切れる前に要約（compaction）されます。最低トークン数は CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS で変えられ、"idleCompaction": false で無効にできます。どちらも v2.1.290 以降で効きます。原文には「in the terminal」とあり、headless 実行が対象になるかは書かれていません。
出典: https://github.com/anthropics/claude-code/releases/tag/v2.1.299

A-2. CLAUDE_CODE_DISABLE_FILE_MENTIONS と /usage の警告追加（v2.1.299）
[確認済] 両AIが一致し、原文も確認しました。@ で指定したファイルは中身ではなくパスだけが渡ります。/usage は、max effort・workflows・常時読み込まれるコンテキスト・大きなツール結果について警告を出すようになりました。
出典: 同上

A-3. 長時間運用でのメモリ増大と、Mod が headless の上限を超えて続く問題の修正（v2.1.299）
[確認済] codex が挙げ、原文で確認しました。直ったのは次の3つです。サブエージェントを多く使ったクラウド／Remote Control セッションを再開したときのメモリ増大。debug ログを大量に出したときのメモリ増大。毎ターン末にプロンプトを投入する Mod が --max-turns・--max-budget-usd を超えて続く問題。
出典: 同上

A-4. サブエージェントの autoCompactWindow と CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL（v2.1.296, 10/9）
[確認済] 両AIが一致し、原文も確認しました。サブエージェントの frontmatter と --agents で、親の会話より早く compaction させられます。workflow エージェントだけを1つのモデルにそろえることもできます。

出典: https://github.com/anthropics/claude-code/releases/tag/v2.1.296

A-5. hooks の --debug ログ強化と、管理設定 hooks の修正（v2.1.296）
[確認済] codex が挙げ、原文で確認しました。command hook の実行が終わるたびに、コマンド・プラグイン・成否・所要時間がログに残ります。対象はツール呼び出し・プロンプト・SessionStart・Stop です。管理設定の PreToolUse で "continue": false を返してもターンが終わらなかった問題と、updatedMCPToolOutput が反映されない問題も直りました。
出典: 同上

出典: 同上

今日の注目

  1. MCP の権限ルールの解釈変更（A-11）と Cowork の破壊的なキー改名（B-4）。どちらも、気づかないうちに権限の範囲が変わる種類の変更です。前方一致に頼った mcp__xxx の allow / deny ルールと、旧名 isDxt* が残っていないかの棚卸しを勧めます。B-4 は旧名のままだと未署名の拡張が読み込まれるので、急ぎで確認してください。
  1. idle compaction（A-1）。長時間のセッションが離席中に勝手に要約されます。headless / cron 実行でも発動するかは原文からは分からないので、実機で確かめ、必要なら "idleCompaction": false を設定してください。キャッシュ前提の knowledge（late-compaction / prompt-cache 系）との整合も確認が要ります。
