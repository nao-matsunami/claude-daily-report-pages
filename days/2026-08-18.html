A. Claude Code — changelog（全項目を原文照合済み）

code.claude.com/docs/en/changelog を直接取得し、Claude の出力にあった v2.1.228〜234 の記述を逐条で突き合わせました。以下は原文と一致した項目です。

A-1. v2.1.234（8/17）— claude-api 組み込みスキルを 200k+ → 約25k トークンに削減

https://code.claude.com/docs/en/changelog

https://code.claude.com/docs/en/changelog

A-3. v2.1.232（8/13）— fork サブエージェント既定ON / セッション間 @ メンション

https://code.claude.com/docs/en/sub-agents

今日の注目

1. v2.1.233 の Todo/Task ツール既定オフ — 自分のパイプラインへの影響が最も大きい

TaskCreate/Get/Update/List と TodoWrite が Opus 4.8 / Sonnet 5 / Fable 5 / Mythos 5 以降で提供停止になりました。このリポジトリの CLAUDE.md・skills・missions に「TodoWrite でタスクを管理する」類の記述があると、指示が空振りしたまま気づかない状態になります。CLAUDE_CODE_ENABLE_TODO_TOOLS=1 で戻せるので、まず grep で依存箇所を洗い出し、「戻す」か「Todo 非依存に書き換える」かを決める価値があります。検証コストは低く、効果は確実です。

2. fork サブエージェントは -p（非対話）では既定OFF — cron/headless 実行が恩恵を受けていない可能性

3. 常時ロード資産のサイズ実測 — 公式が自ら claude-api スキルを 200k+ → 25k に削った
