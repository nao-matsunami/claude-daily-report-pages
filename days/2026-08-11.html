今日の注目

1. 8/17 のレガシー Workbench + 実験的 prompt tools API 廃止 — 残り 6 日

3AI のうち Claude だけが拾い、私が platform リリースノート原文で確認しました。/v1/experimental/generate_prompt / improve_prompt / templatize_prompt は 8/17 以降エラーを返します。Workbench の保存済みプロンプト・変数・evals は新 Workbench(playground)に引き継がれないため、エクスポートが必要ならデッドライン付きの実作業です。今日挙がった全項目の中で唯一、期限があり後戻りできません。まずリポジトリとスクリプトを grep -r 'experimental/\(generate\|improve\|templatize\)_prompt' で洗うのが最初の一手。

2. クロスセッション・メッセージング × サブエージェント 200 上限撤廃 の組み合わせ

どちらも v2.1.224 で同時に入り、しかも Anthropic 自身が 8/10 の Riemann 記事で「約 60 体のサブエージェントを統括した」と書いています。この 3 つは同じ方向を向いており、偶然ではなさそうです。実装検証として価値があるのは、① 長寿命の調査セッションで 200 体超のサブエージェントを実際に回して劣化点を測る、② 調査セッション → 実装セッションへ SendMessage で要点だけ渡す構成を組み、従来の「共有 scratch file + hook + polling」と比べる、の 2 つ。既存知見の延長線上にあり、検証コストも低めです。
