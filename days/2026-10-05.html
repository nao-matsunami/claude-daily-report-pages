2. Claude Code（重点）

Claude Code Mods（v2.1.287、2026-10-01）

[確認済] Mod は TypeScript の関数で、プラグインに入れて配布します。プロンプトの書き換え、UI の追加、組み込み機能の置き換えができます。サンドボックスはなく、Claude Code と同じマシン権限で動くため、公式も「信頼できる提供元のものだけ入れる」よう注意しています。/diff も Mod として実装されています。Team/Enterprise では、組み込み Mod の sec-default が最初に読み込まれ、危険な Mod の導入を防ぎます。（確認経路: claude.com/blog/claude-code-mods と changelog 2.1.287 を直接取得）
https://claude.com/blog/claude-code-mods
