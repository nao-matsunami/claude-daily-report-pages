Claude Sonnet 5.5 リリース(2026-09-28)

[確認済] 料金は $2/$10 per MTok、キャッシュ読み取り $0.20、書き込み $2.50。「30%以上速い」「ほとんどの作業で最大30%安い」とあり、AWS・Google Cloud・Azure で使えます。thinking をオフで使っている場合は、移行前に between_tools 設定へ切り替える必要があります。いずれも anthropic.com の製品ページ原文で確認しました。補足として、収集では「ツール呼び出しが少なくシェル実行は半分」と書かれていましたが、原文ではある1社の早期テスターの報告(「ツール呼び出しが3分の1減り、シェル実行がおよそ半分」)です。公式全体の数字ではありません。
出典: https://www.anthropic.com/claude-sonnet-5-5

[確認済] 「now default Sonnet on Anthropic API」、コンテキスト1M。changelog 原文で確認しました。
出典: https://code.claude.com/docs/en/changelog

Opus 5.5 の長時間セッション向けブログ(2026-09-24)

[確認済] 一般的なトークン課金の使い方で Opus 5 より約40%安く、キャッシュ読み取り単価は60%下がりました。Claude Code でキャッシュミスする入力は50%以上減ったとのことです。推奨は3点で、①モデルはセッションの最初に決める ②離席する前に compact する ③API で長いセッションを回すなら1時間キャッシュを使う、です。claude.com blog 原文で確認しました。
出典: https://claude.com/blog/claude-opus-5-5-built-for-coding-sessions-that-use-more-context

今日の注目

  1. verify skill の自動実行(2.1.286)が自動化に影響しないか確かめる。 当リポジトリやユーザー設定に verify という名前の skill があると、コミット直前に勝手に実行されるようになります。cron の headless 実行のコミット経路にも効くのかは、changelog だけでは分かりません。既存知見(cc-verify-codereview-autorun-stopped)とも食い違う可能性があり、実機で確認する価値が最も高い項目です。
  2. 2.1.288 に上げて、パス指定の rules とフックの fail-closed 化を確認する。 これまでは、Write/Edit でファイルを作っただけだとパス指定の rules が読み込まれていませんでした。また PreToolUse フックのガードが、マッチ失敗やシリアライズ失敗のときに飛ばされていました。直った結果、今まで通っていた呼び出しがブロックされるようになる可能性があるので、フックでガードしている構成は実機で確認してください。
  3. auto mode 既定化(2.1.284)と、10/6 の Cowork クラウド移行への備え。 auto mode のほうは、既存知見(8/14 発効の既定化)と対象範囲がどう重なるかを決着させる必要があります。Cowork のほうは期日が決まった変更で、ローカルファイルを使うスケジュールタスクが10/6以降、デスクトップアプリが開いていないと動かなくなります。
