今日の注目

1. MCP 2026-07-28 への Claude 対応(項目18)— 最優先
期間内で唯一の実質的な製品発表であり、かつ 3AI 中 1つも確定情報として拾えていなかった項目です。特に MCP tunnels(リサーチプレビュー) は、社内ネットワークの MCP サーバーを公開せずに Claude へ繋げる話で、ローカル/自宅サーバー構成を持っている環境では試す価値が大きい。IdP 経由のコネクタ配布も、個人利用なら不要ですが仕様として押さえておく意味があります。

2. ネストサブエージェント深さ3(2.1.219)+ workflowSizeGuideline(項目7)
期間外ですが、エージェント構成の設計に直接効く変更です。既定で深さ 1→3 に緩和されたため、これまで書けなかった多段オーケストレーションが動くようになる一方、意図せずエージェント数が膨らむリスクもあります。CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH と workflowSizeGuideline を settings で明示的に固定しておくのが、今すぐできる実用的な対処です。

3. Artifacts の MCP コネクタ ライブデータ(項目16)
Gemini が Claude Design の機能と取り違えていた本体。公開した artifact が閲覧者自身のコネクタで毎回ライブデータを取りに行く仕組みで、ダッシュボードの作り方が変わります。CLI が v2.1.209 未満だと静的スナップショットに落ちる点と、コネクタを呼ぶ artifact は公開リンク共有ができない点が実装上の落とし穴です。

確認できなかったもの(推測で補完していません): Fast mode の 2.5倍という速度数値、Cowork の Opus 5 による精度向上、Cowork 2倍キャンペーンの現在の実施状況、Fable 5 プロモと AI for Science グラントの 8/2 期限、ステータス履歴の分単位の詳細。
