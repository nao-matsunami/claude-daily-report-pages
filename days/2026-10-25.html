A. Claude Code(最重視)

A-1. ネストした巨大 CLAUDE.md で compaction が繰り返し起きる問題の修正(v2.1.309)

[確認済](両者一致+changelog 原文)
v2.1.309(10/22)の修正です。サイズ上限を超えたネスト CLAUDE.md は、冒頭だけが読み込まれるようになりました。原文: "a nested CLAUDE.md over the size limit now loads only its start"。
出典: https://code.claude.com/docs/en/changelog

A-2. MCP ツールが多いセッションで「prompt is too long」と表示され、不要な compaction が走る問題の修正(v2.1.306)

出典: 同上

A-6. hooks まわりの変更(v2.1.304 / v2.1.307 / v2.1.309)

[確認済](両者一致+原文。ただし一部の表現を訂正)

  • v2.1.304: 先に実行されたプラグインが mod の hook をスキップしたとき、transcript に行が出るようになりました。原文が書いているのは「イベント名とプラグイン名を表示する」ことで、codex の言う「理由を表示」とは厳密には違います。

今日の注目

  1. v2.1.309 の sandbox 修正と sed -i / /rewind の変更(A-7、A-9)
  • シェルの起動ファイルがサンドボックス外で実行されていたのはセキュリティ上の修正で、無人運用ではバージョンを上げる価値が高いです。
  • sed -i が /rewind で戻らなくなったので、自動化スクリプトが /rewind に頼っていないか棚卸しする必要があります。
  • claude ultrareview に --trust-workspace が必須になったので、スクリプトから呼んでいる箇所も確認が必要です。
  1. claude_code.safety_event(v2.1.307)
  • 権限ルール・hook・サンドボックスが止めたツール呼び出しが OTel に出るようになりました。
  • 既存の deny 床が実際に効いているかを、ログで観測できるようになります。
  • 2.1.307 の fork 役割混同の改善とあわせて、並列 fork で重複作業が減ったかも確かめられます。
  1. 巨大なネスト CLAUDE.md の扱い(A-1)と、公式記事のツール 30〜50 個の閾値(E-1)
  • サイズ上限を超えたネスト CLAUDE.md は冒頭しか読まれなくなったため、後半に書いた指示が効かなくなっている可能性があります。
  • ネスト CLAUDE.md のサイズ棚卸しと、MCP ツール数の確認を一緒に行う価値があります。
  • 上限の具体的な値は、今回の changelog 原文では確認できていません。
