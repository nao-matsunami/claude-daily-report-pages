Claude Code

2.1.287（10/1）: Claude Mods と組み込みの mod「You should know」

[確認済]

  • Mods は、プラグインに入れた JS/TS のイベントハンドラを Claude Code と同じプロセスの中で動かす仕組みです。ツール呼び出し・プロンプト・UI の描画に介入できます。同じ版で agents view の n:<text> フィルタと、/config の UI 改善も入っています。
  • 二次情報（substack）が挙げていた3点は、すべて一次情報と合っていました。
  • 有効化は /plugin enable cc-plugin-you-should-know@builtin で、初期状態はオフ。
  • 動くのは「first-party sessions with telemetry on」のときだけ。
  • /diff は組み込みの mod（cc-plugin-diff）として実装されている。
  • 確認経路：changelog の 2.1.287 の項と、Mods overview の「Mods built into Claude Code」の表。
  • 運用上の注意も公式に書かれています。
  • disableAllHooks・--bare・--safe-mode では組み込みの mod は止まりません。
  • mod は ask ルールや PreToolUse hook が止めた呼び出しも承認できます。
  • 出典：changelog / Mods overview
