今日の注目

1. Fable 5.1 の API 破壊的変更 — tool_choice: any / tool が 400 エラーになる(A-4)
今週で唯一、既存の自動化を無音ではなく即座に壊す変更です。forced tool use を使っているコードがあれば Fable 5.1 に切り替えた瞬間に落ちます。thinking ブロックの prefix チェックも、8/31 以降作成アカウントでは過去ターンを編集する系の自動化(要約差し込み、履歴書き換え)を 400 にします。自リポジトリの tool_choice と履歴操作を今日中に grep する価値があります。移行先は strict tool use / structured outputs。

2. プロンプトキャッシュ修正群 + /cost のキャッシュミス原因表示(B-3, B-4)

3. /skill-doctor + スキルリスティング 1% 予算(B-9, B-10)
-p でテキスト出力できるので非対話で棚卸しが回せます(v2.1.252 以降、feature-flag fetch を切っていないこと)。重要なのは 1% 予算の挙動で、スキルを増やしても名前は必ず載るが、溢れると呼び出し頻度の低いものから description が削られる — つまり「使っていないスキルが、使っているスキルの説明文を痩せさせて呼び出し精度を下げる」という因果があります。これは公式ドキュメントで確定した仕様なので、棚卸しの費用対効果が読めます。
