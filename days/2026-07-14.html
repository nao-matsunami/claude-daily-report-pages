今日の注目（検証・実装を試す価値のある更新）

  1. Claude Code v2.1.207 の auto mode 解禁（Bedrock/Vertex/Foundry） ― 最も具体的・公式確認済みで実務インパクト大。環境変数ゲートが外れた＝既存の企業クラウド環境で自律実行が既定で到達可能になった点は、権限・安全設定（disableAutoMode、settings.local.json の autoMode 無視化）の見直しが即必要。実機で挙動確認する価値が高い。
  1. Cowork の Web/モバイル・バックグラウンド実行 ― 3AI一致＋公式で最も堅い今週の目玉。「端末を閉じてもクラウドで継続」「Chat とホーム統合」は運用フローが変わるので、実際にモバイルでタスクを起動→別端末で回収、を試して挙動と制限（8/5までの2倍枠）を体感しておくと良い。
  1. Microsoft 365 書き込みツール ― メール送信・カレンダー更新まで踏み込む破壊的操作を伴うため、attribution ヘッダ・レート制限・添付非対応などのセーフガードを、有効化前に自組織のポリシーと突き合わせて検証する価値がある。

※ Claude Design は今週の新機能ではない（6/17の大型改修が最新）ため、注目からは外しました。Gemini の「Claude Code 週50%緩和プロモ」「HITLプッシュ通知」「Dynamic workflow size」は裏が取れず、実装検証の前に一次確認が必要です。
