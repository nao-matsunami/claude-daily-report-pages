今日の注目

  1. v2.1.307 の claude_code.safety_event（OTel）

cron で動かしている claude -p や auto mode の運用で、どの層（ルール / auto mode / フック / サンドボックス）が止めたのかをログから集計できるようになりました。auto mode が過剰にブロックしていないか、フックが fail-open していないかを定量的に見られる初めての手段です。既存の知見（auto-mode-default-impact-on-cron-scripts、hooks-timeout-fail-open-primary-check）の実測による裏付けに使えます。

  1. v2.1.309 / v2.1.311 の CLAUDE.md 関連変更と SubagentStop 修正
  • サイズ上限を超えたネスト CLAUDE.md は先頭しか読まれない仕様になりました。
  • 長いリスト項目があるとフリーズする問題が修正されました。
  • SubagentStop フックが約1分に2回発火していた問題が、終了時1回に修正されました。

CLAUDE.md の後半に置いた規則が無視されていないか確認する価値があります。SubagentStop を使うフックは、これまで重複発火を前提にしていなかったかも確認したほうがよいです。棚卸しは小さく済み、効果は直接出ます。

  1. v2.1.307 の /claude-api api-version と SDK メジャー更新（API 2026-10-21）

400 になる件は検証済みです。ただし SDK 側には API バージョンとは独立した破壊的変更とライセンス変更があり、こちらはまだ棚卸ししていません。SDK を固定せずに使っているスクリプトがあれば、次に更新したときに壊れる可能性があります。/claude-api api-version が何を書き換えるかを試す価値があります。
