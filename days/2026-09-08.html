3AI(agy/codex/claude)突き合わせ + Claude審判。確度ラベルを必ず確認すること。

3つの出力を突き合わせ、一次情報（anthropic.com / code.claude.com / claude.com/docs / support.claude.com / GitHub CHANGELOG）に当たって検証しました。既存 knowledge の該当分は参照先を付けています。

A. モデル・プラットフォーム

A-1. Claude Fable 5.1 / Mythos 5.1 発表（9/1） — [確認済]
3AI一致。公式ページを直接取得し、モデルID claude-fable-5-1、入力$10 / 出力$50 per MTok 据え置き、cache read $0.25/MTok（Fable 5比75%減）、「通常ワークロード約25%・エージェント的タスク最大45%のコスト減」を確認。Mythos 5.1 は米国組織限定の trusted access（Cyber / Life Sciences Verification Program 経由）。既定 effort は Claude Code=High、Cowork / claude.ai=Medium（codex の主張どおり原文にあり）。
https://www.anthropic.com/claude-fable-and-mythos-5-1

A-2. 仕様（1M context / 128k出力 / adaptive thinking） — [確認済（1M のみ）／要検証（128k出力）]
1M コンテキストは Claude Code changelog v2.1.257 の原文「1M context」で確認。「最大出力128kトークン」「always-on adaptive thinking」は今回取得した発表ページ本文に該当記述を確認できませんでした（＝存在しないと確認したわけではありません。モデル仕様ページ未取得）。

A-3. 公式ベンチマーク — [確認済]
発表ページの表から確認：Terminal-Bench 4.0 = Fable 5.1 55.8% / Mythos 5.1 60.9%、Terminal-Bench-Science 0.1 52.6%、HLE 60.9%（ツールなし）/ 65.0%（ツールあり）、CursorBench 3.2.0 73.4%、OSWorld 2.0 77.9%（partial）/41.7%（strict）、GDPval-AA v2 1853、AutomationBench 31.4%。Gemini の「HLE 60.9%」「TB4.0 55.8%」「TB-Science 52.6%」はいずれも正しい数字です。

A-4. SWE-bench 系の数値（95.0% / 80.0% など） — [要検証]

A-5. Artificial Analysis Intelligence Index 66（歴代最高） — [要検証]
Gemini 単独。公式ページに記載なし、第三者ベンチのため一次は Anthropic ではありません。未確認。

A-6. サイバー／バイオのセーフガード緩和 — [確認済（ただし文言に注意）]
公式原文は「false positives が60%減」「バイオは良性リクエストに対する介入が Fable 5 比 85% 減」。codex の「safeguard 介入が平均約60%減」は誤検知の減少を指すので言い換えとしてはやや広すぎます。Fable 5.1 で防御目的の脆弱性発見が許可された点は一致。

A-7. API 破壊的変更（forced tool use / thinking block） — [確認済]
Forced tool use 非サポート、旧モデルは 5.1 の thinking block を読めない、過去ターン編集で thinking block 無効化。いずれも公式 whats-new ページで逐条確認済み。加えて発表ページには新規 API アカウントは多ターン会話の過去コンテキストを手動編集できない（anti-distillation）とあります。

A-8. EU AI Act 対応の不可視テキスト透かし — [確認済]
2026-08-02 以降にリリースされたモデルの出力に適用、検出 API は private preview。codex 単独主張でしたが発表ページ本文で確認。

A-9. Enterprise Frontier Safeguards（9/1） — [確認済]
ZDR と不正検知の両立、データは顧客管理クラウドに保持。対象は Claude Code / Enterprise / Platform / Bedrock / Google Agent Platform / Microsoft Foundry。「this fall から段階展開」で、それまでは対象顧客に Fable 5 / 5.1 の ZDR を暫定提供。
https://www.anthropic.com/news/enterprise-frontier-safeguards

A-10. ant CLI v1.30.0 / ant apply（9/3） — [確認済]
公式ドキュメント「Manage resources as code with ant apply」が実在（agents / environments / skills / memory stores / deployments を Markdown・YAML で宣言、claude-lock.json でドリフト検知、--dry-run / --yes で CI 運用）。v1.30.0 以降が必要という記述も docs 側にあり。ただし「9/3リリース」という日付自体は二次情報です。
https://platform.claude.com/docs/en/cli-sdks-libraries/cli/apply

A-11. Commerce agents blueprint（9/2） — [確認済（一次ページは未取得）]
Claude 単独主張だが、Apache-2.0 の anthropics/commerce-agents、小売・旅行・通信・チケッティングの参照実装、Claude Code プラグイン同梱という内容で独立した二次情報が多数一致。anthropic.com/news/claude-commerce-agents は 404 で、私は一次ページのURLを特定できませんでした（不在の確認ではありません）。

A-12. Sonnet 5 の導入価格が恒久化 — [確認済]
pricing ページ Note に「9/1 予定の $3/$15 への値上げは行われない」と明記済み。ただし Gemini の「2026-09月初旬に撤回」という時期は誤りで、確定は 8月中旬時点です。

B. Claude Code（重点）

版数は GitHub CHANGELOG 原文で照合しました。

B-1. v2.1.257（9/1） — [確認済]
Fable 5.1 追加（既定 Fable モデル、1M、$0.25 cache read）／auto mode に Containment Escape ルール（クラウドメタデータ資格情報取得・egress回避・クロステナント到達を自動承認しない）／CLAUDE_CODE_SUBAGENT_MODEL_FORCE／/effort に s（当該セッション限り）。
※ Gemini はこの3件を「v2.1.261/263」の内容として並べており、版数帰属が誤りです。

B-2. v2.1.258（9/2） — [確認済] macOS 12 起動不能（2.1.255 のリグレッション）とリモート/スケジュールセッションの修正のみ。Claude のみが記載。

B-3. v2.1.259（9/2） — [確認済]
managedMcpServers（組織が HTTP/SSE MCP を全ユーザーに配布、コマンド実行型エントリはスキップ）／--permission-prompts none（無人 headless：プロンプトが要る操作は自動 deny、権限モード自体は生きたまま）。日付は codex=9/2・Claude=9/3 で割れており、docs 側表記は 9/2。

B-4. v2.1.260（9/3） — [確認済]
フルスクリーンの /diff パネル／/cost とステータスラインの prompt_cache にキャッシュミスの推定原因（ツール定義・システムプロンプト変更、TTL超過）／Fable 5.1 で tool result 後のコンテキストがキャッシュ対象外になり毎ツールターン再送されていた不具合の修正／model: fable が [1m] タグを無視して 200K で走る不具合の修正／/reload-plugins の headless 対応／/advisor のテキスト形式。
[要検証（版数のみ）]: 「1M モデルの auto-compact 改善」と「サブエージェントのバックグラウンドコマンド1時間上限の撤廃」は、CHANGELOG の取得のたびに 2.1.257 / 2.1.260 / 2.1.261 と帰属が揺れました。機能の存在は確認済、載っている版数だけ未確定です。

B-5. v2.1.261（9/4） — [確認済]
/skill-doctor（未使用スキルとその context コストを提示）／bashOutputMaxChars / taskOutputMaxChars（最大128K文字）／--append-subagent-system-prompt-file／/status・claude doctor の「Organization policy」行／セッション再開時に並列ツール呼び出し周辺の hook 出力が失われる不具合の修正／/ultrareview の待機を30→45分に延長。3AI とも内容は一致。

B-6. v2.1.262 / v2.1.263（9/6） — [確認済・Claude の記述を訂正]
2.1.262 は CHANGELOG に存在し、2.1.263 と同じく「Bug fixes and reliability improvements」の一行のみ。Claude の「2.1.262 は見当たらず (未確認)」は誤りです。

B-7. /skill-doctor の必要バージョン — [要検証]
skills ドキュメントは「v2.1.252 以降が必要」と記す一方、CHANGELOG では 2.1.261 で追加。どちらかが古い/誤りの可能性があり、決着していません。

B-8. スキルリスティングは context の1%、skillListingBudgetFraction で調整 — [確認済]
公式 skills ドキュメント原文「The budget scales at 1% of the model's context window.」および skillListingBudgetFraction（例 0.02）／SLASH_COMMAND_TOOL_CHAR_BUDGET を確認。Claude の「二次情報のみで未確認」は訂正。context: fork も同ページに正式記載。

B-9. 週次利用枠：9/13 に暫定+50% 終了、9/14 から恒久+25%（実質約17%減） — [確認済（内訳に注意）]
暫定+50% の 9/13 終了と対象プランは support.claude.com の一次記事で確認済み。「+25%／約17%減」は Anthropic 公式アカウントの投稿が出所で、Anthropic のウェブページ上には存在しません。また「150→125」は二次メディアの説明用指数であり公式数値ではありません。Gemini の記述はこの区別をしていない点だけが不正確です。

C. Claude Cowork

C-1. v1.46388.3（9/4）ホームフォルダ／ドライブ全体のアタッチ対応 — [確認済]
Windows の Documents・AppData、macOS の Library、ドライブ全体を添付可能に。ただし Claude 自身の設定・セッションデータ、SSH鍵・AWS/GCP 資格情報・シェル起動ファイルは対象外。Claude のみが挙げた項目で、公式 changelog で確認。
https://claude.com/docs/cowork/changelog

C-2. 非推奨設定フィールドのアプリ内警告（9/10 から） — [確認済・Claude の「一次未確認」を訂正]
9/10 から dismissible な通知、受付停止24時間前にもう一度表示、Details ダイアログに置換先と期限、管理者向けの Copy report。disableConfigDeprecationWarnings で初回表示のみ抑止可能（最後の24時間通知は出る）。

C-3. 組み込みブラウザ / Claude in Chrome の既定値 — [確認済]
Team は展開に伴い既定ON、Enterprise はローンチ時OFFで 2026-09-10 から既定ON（管理者が明示的にOFFにしていない限り）。両方使える場合は Settings > Cowork の Preferred browser でユーザーが選択。codex の記述どおり。

C-4. クラウドバックグラウンドセッション／チャットとの共有メモリ — [確認済（ただし今週の新機能ではない）]
クラウド実行の Cowork はラップトップを閉じても継続、メモリは Claude.ai チャットと共有（ローカル実行の Cowork はメモリを使わない）。共有メモリの発効は 2026-08-25 前後で、9/1〜9/8 の changelog には該当エントリがありません。Gemini は「8月下旬〜9月初旬」と幅を持たせているので誤りではありませんが、今週の更新ではない点は明確にすべきです。

C-5. 「組み込み Chromium ブラウザ」という固有名 — [要検証]
公式は "a browser built into Claude Cowork" としか書いておらず、Chromium という記述は一次で確認できませんでした（技術的には正しい可能性がありますが、Gemini の固有名付加は裏が取れていません）。
