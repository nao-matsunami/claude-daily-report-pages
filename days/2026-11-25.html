今日の注目

  1. /code-review の範囲縮小（2.1.328）と、予約タスクの再登録（2.1.329）の影響確認

自動化から /code-review を呼んでいて、整理系の指摘を期待している場合は /simplify も併用する必要があります。また、旧版で保存した予約タスクは、新しいセッションでは多くが黙って動かなくなる可能性があります。定期実行への依存を一度洗い出す価値があります。

  1. Cowork v7.37095.0 の macOS plugin hooks 実行方式変更

公式が「1台で試してから展開」と案内している、破壊的になりうる変更です。plugin hooks を使っているなら、更新前に1台で動作確認するのが妥当です。同じ版の MCP タイムアウト3分化とハードリンク禁止も、Cowork 上のスクリプトに影響します。

  1. claude doctor の API 接続診断（2.1.331）

ブリーフ収集で OAuth が失敗したときにエラー本文がそのまま commit される問題に対して、収集の前に到達性を確かめる手段として使える可能性があります。非対話で出力をどう扱えるかは、実際に試して確認する必要があります。
